本主题不引入数学渲染引擎，因此不解析美元符号包裹的公式。需要呈现公式时，应把公式放进围栏代码块，或改写为普通文本叙述。

## 行内代码

行内代码用反引号包裹，适合表示字段名、文件名与短表达式。行内代码内的方括号不会被当作双链解析，因此可以安全书写语法示例。

## 围栏代码块

围栏代码块用三个反引号开启并标注语言。代码块内容原样输出，不参与链接解析与 Markdown 渲染。

```js
// 计算链接密度
const density = links / pages;
console.log(density.toFixed(2));
```

```
f(x) = a*x^2 + b*x + c
```

## 公式的替代表达

公式可以写成文字描述、变量表或伪代码。以二次函数为例：

| 组成部分 | 含义 |
|---|---|
| 二次项系数 | 决定开口方向与宽窄 |
| 一次项系数 | 影响对称轴位置 |
| 常数项 | 决定与纵轴的交点 |
