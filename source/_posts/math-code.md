主题内置 KaTeX（本地资源，无 CDN 依赖），支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]` 数学公式；代码块内的 `$` 不会被误渲染。

## 行内代码

行内代码用反引号包裹，适合表示字段名、文件名与短表达式。行内代码内的方括号不会被当作双链解析，因此可以安全书写语法示例。

## 围栏代码块

围栏代码块用三个反引号开启并标注语言。代码块内容原样输出，不参与链接解析与 Markdown 渲染。

```js
// 计算链接密度
const density = links / pages;
console.log(density.toFixed(2));
```

## 数学公式

行内公式用单个美元符号包裹，例如 $E = mc^2$ 与 $\frac{a}{b}$；块级公式用双美元符号：

$$
\int_0^1 x^2 \, dx = \frac{1}{3}
$$

也支持 `\( ... \)` 与 `\[ ... \]` 写法。公式只在所在页面按需加载 KaTeX，不会拖慢其他页面；深色模式下会自动继承文字颜色。

## 公式与代码的边界

代码块里的 `$x^2$` 会原样显示，不会被当成公式。每个代码块右上角有「复制」按钮，方便直接取用。

| 写法 | 渲染结果 |
|---|---|
| `$E=mc^2$` | 行内公式 |
| `$$ ... $$` | 块级公式 |
| `\( ... \)` | 行内公式（LaTeX 原生） |
| `\[ ... \]` | 块级公式（LaTeX 原生） |
