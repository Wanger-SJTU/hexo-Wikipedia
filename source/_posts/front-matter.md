页面属性指 Markdown 文件顶部的 YAML 区块，用于描述条目的元数据。主题的侧栏、搜索、统计与信息框都从这些字段读取数据。

## 必填与可选

标题与日期为必填字段，其余均可省略。标题同时是双链解析的主键，因此同一站点内不应重复。摘要会出现在搜索结果与悬浮提示中，建议用一句完整陈述说明条目主题。

| 字段 | 是否必填 | 作用 |
|---|---|---|
| title | 是 | 条目标题与双链主键 |
| date | 是 | 创建时间 |
| updated | 否 | 最后编辑时间 |
| summary | 否 | 搜索与提示摘要 |
| navigation | 否 | 侧栏父分组路径 |
| nav_title | 否 | 侧栏显示名 |
| nav_order | 否 | 同级排序 |
| nav_hidden | 否 | 不显示于侧栏 |
| aliases | 否 | 双链别名列表 |

## 信息框

`infobox` 字段用于生成条目右上角的信息框，支持图片、图注与若干「标签—值」对。字段嵌套为对象与数组，缩进敏感，建议参考已有条目复制修改。
