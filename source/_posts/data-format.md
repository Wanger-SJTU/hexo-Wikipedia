站点生成时会产出若干静态数据文件，供图谱、搜索与统计页面读取。它们都是普通文件，可以直接用文本工具检查。

## 文件清单

| 文件 | 内容 |
|---|---|
| 图谱数据 | 节点与连线，包含缺失目标标记 |
| 搜索数据 | 标题、摘要、标签与正文纯文本 |
| 统计数据 | 页面数、链接数与各类榜单 |

## 节点结构

图谱数据的节点包含标识、标题、地址、分组、标签与出入度；连线包含起点、终点与重复次数。标识由源文件路径去掉扩展名得到，在同一站点内唯一。

```json
{
  "nodes": [
    { "id": "_posts/wikilinks", "title": "双链语法", "group": "指南", "in": 4, "out": 6 }
  ],
  "links": [
    { "source": "_posts/intro", "target": "_posts/wikilinks", "count": 1 }
  ]
}
```

## 使用建议

数据文件适合做外部校验，例如用脚本核对统计页显示的数字。字段发生变化时应同步更新依赖它的页面；图谱的渲染逻辑见 [[关系图谱]]，指标口径见 [[链接统计]]，配置入口见 [[主题配置]]。
