### 为什么需要内存模型
内存模型是因现代处理器对缓存以及多核运算的支持引出的。早期的单核无缓存结构的处理器而言，指令都是单线程运行的，同一个变量也只会存在一份，这种情况下所有行为都是可以预期的。
对含有cache的结构，存在cache到memory的的一致性问题；对多核的CPU情形，则存在不同CPU核的顺序问题以及多份变量的同步一致性问题。

#### 简单的多线程访问数据问题
假设在程序执行之前，A=B=0，有两个线程同时分别执行如下的代码：

|     | 线程1      | 线程2        |
| --- | ---------- | ------------ |
| 1   | `A=1`      |    |
| 2   ||  `B=2`     |
| 3   |     `print(B)`         |              |
| 4   |            |     ` print(A) `         |

上述程序的执行结果是一个简单的排列组合问题，其结果有：

> 2（先选择A或B输出）* 2（输出修改前还是之后的结果）* 1（前面第一步选择了一个变量之后，现在只能选剩下的变量）* 2（输出修改前还是之后的结果） = 8

其可能的结果包括：`(0,0)、(1,0)、(0,2)、(1,2)、(0,1)、(2,0)、(2,1)`。
| A   | B   |  执行顺序   |
| --- | --- |---  |
| 0   | 0   | 
| 1   | 0   |
| 0   | 2   |
| 1   | 2   |
