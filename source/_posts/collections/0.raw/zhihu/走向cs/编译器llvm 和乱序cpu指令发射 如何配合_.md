首先，这里有两个优化问题。

- 指令乱序优化
- 多发射CPU优化
指令乱序优化
如果指令不乱序执行，那么如果两条连续的指令遇到以下的相关问题，那CPU则必须停顿一个或者多个时钟周期，才能保证两条相关指令的正确执行

- 结构相关：CPU某个部件的单元不足够，导致的多条指令不能同时执行
- 数据相关：下一条指令的数据，来源于上一条指令的结果，而在上一条指令还没执行完，导致下一条指令必须等待上一条指令执行完后，才可以继续执行
- 控制相关：遇到条件分支指令，CPU无法判断下一条指令是什么，产生一次停顿所以LLVM的作用，或者更广泛的说，编译优化技术，使用乱序执行代码技术，来尽可能少的减少CPU的停顿

多发射CPU优化
多发射CPU的技术，可以让多条无关指令同时运行，来加快代码的执行效率，

这一般应用在循环体内

例如以下代码

for (int i=0; i<n; i++)
{
    b[i] = a[i] + 1;
}

通过llvm优化，或者更广泛的说，通过编译优化技术，把循环体张开，如下

for (int i=0; i<n; i=i+8)
{
    b[i] = a[i] + 1;
    b[i + 1] = a[i + 1] + 1;
    b[i + 2] = a[i + 2] + 1;
    b[i + 3] = a[i + 3] + 1;
    b[i + 4] = a[i + 4] + 1;
    b[i + 5] = a[i + 5] + 1;
    b[i + 6] = a[i + 6] + 1;
    b[i + 7] = a[i + 7] + 1;
}

那么8发射的CPU就可以同时执行循环体的代码了
