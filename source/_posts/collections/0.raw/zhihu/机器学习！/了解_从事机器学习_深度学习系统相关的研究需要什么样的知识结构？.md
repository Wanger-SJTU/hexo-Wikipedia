最好的资源，应该是伯克利最近新开的课程AI system AI-Sys Spring 2019。

这个课首先把深度学习经典（AlexNet）以及时髦的结构（Graph NN）走马观花的过一遍，然后将机器学习系统这个课题分了许多子类（框架，强化学习系统，分布式系统， 安全系统......)，每个子类挑了几篇漂亮的论文。讲课的两位神牛，保证了这些材料的质量。

啊，为什么不早点开这门课程！

在这个领域已经艰难的爬了一段时间，发现相对于之前的deep learning，它最难的一点在于发现问题，然后为了这个问题，讲述一个美轮美奂的story来解决他。

不像CV，子课题明确（人脸，目标检测，VQA...)，STOA就在那里摆着，公开的benchmark又那么多，大家撸起袖子加油干就好了。AI system，有了“system”这个词，这件事就变得好扑朔迷离（应该是我太菜了），很多文章总给人这样的感觉“这都能发？牛！”

比如Weld这个项目，现在的AI核心还是喂数据，他们就做了个runtime来抽象整个工作流的各种数据格式，提高整体的运行效率。这样的点子大家肯定都有，但看到人家的代码和paper，只能说一句“真硬”。

再比如[ray-project/ray](https://link.zhihu.com/?target=https%3A//github.com/ray-project/ray)，这个深度强化学习的training，simulation，serving框架，真是牛的没边了，同时还带来了另一个独立的项目arrow，Apache Arrow Homepage（评论区惊现大佬，感谢指点arrow和ray的关系， credit：ray因为memory的问题做了一个shared memory object store叫plasma，然后plasma的serialization format是arrow format。arrow是Pandas的作者Wes Mckinney和一堆人做的data interchange format, 之后plasma就纳入进了arrow project）。发展到现在，ray已经完全不再是单纯为深度强化学习服务了，变得像一个python的分布式运算框架了，感觉在它的基础上可以做很多有趣的工作。

当然也有一些很确定的子课题，像做tensorflow，pytorch这种机器学习框架（个人免入），像分布式训练（大公司PR必备，这个月imagenet训练1小时，下个月就变15分钟），这些都是公司的军备竞赛场所，门槛有些过于高了。

说的感觉自己都有点儿乱，AI系统真的太博大精深，知识结构还是得看个人做啥。做CV系统就读一些CVPR的硬核文章（例如目标检测），然后找场景做应用系统（比如SIGCOMM18的文章Chameleon）开始练手，想清楚story后就奔着latency，throughput这些性能指标刚，再疯狂看相关代码和NSDI，OSDI，SIGCOMM，CIDR等等上面的文章，知识体系应该就能一点点儿建立起来了。

### 3.16更新：


第二好的资源我觉得应该是Jeff Dean，Fei-Fei Li，Jordan等一众大牛创立的SysML会议上的论文，去年刚成立是4页，今年就变长文10页了。

还有就是NIPS的Machine Learning System workshop的论文。

上面这两个会议的论文读起来会比NSDI，OSDI这些传统老牌系统会议轻松一些，比较适合入门打基础，感觉充满了生机。

其实这个领域已经很火了，要做的东西看起来也非常多，应该会越来越火。

自己慢慢收集了一个List，欢迎一起舔砖加瓦star：[https://github.com/HuaizhengZhang/Awesome-System-for-Machine-Learning](https://link.zhihu.com/?target=https%3A//github.com/HuaizhengZhang/Awesome-System-for-Machine-Learning)

### 3.19更新：


没想到收到这么多关注，这个领域已经这么火了吗。小弟诚惶诚恐。

在知乎上，这个领域的巨佬肯定是 @陈天奇

 ，他的课程CSE 599W System for ML，因为看的时间太久了，竟然忘了推荐，必备读物。

因为理论姿势水平不行，上面更多的是从实践的角度推荐的资料，不是很了解系统理论的做法。

继续站在实践角度，觉得做系统最重要的是合作，上面谈及的[ray-project/ray](https://link.zhihu.com/?target=https%3A//github.com/ray-project/ray)，或者自己比较喜欢的另一个work，[scanner-research/scanner](https://link.zhihu.com/?target=https%3A//github.com/scanner-research/scanner)，或者大家都知道的mxnet，这些牛的不行的系统，都是若干个强力PhD大神合作的结果，直观感觉上，系统作者名单的长度也是远大于AI相关论文作者名单的长度。成长最快、建立知识体系最迅速的方式，自然是能加入一个好的项目，观摩大神工作，写写修修补补的代码，慢慢变得独当一面。（一个人钻真心好累）
