在深度学习里，“vector embedding”似乎应该说是“metric embedding”比较妥当。 我们将 词语或句子 嵌入 到 <strong>度量空间</strong> (metric space) 而不是 <strong>向量空间</strong> (vector space).  但一般搞计算机的人对数学都比较“sloppy”，他们见到一串数字就很自然地叫它“vector”，其实这串数字更确切是一个空间或流形上的「坐标」而已。

<strong>Word2vec</strong> 是「词向量」的鼻祖，甚至可以说，它是当下 LLM 空前成功的源头。 大家肯定见过这个例子（左图）：

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_341ce8be73b1.jpg)

$我一直在思考，为什么词向量好像有某种「方向性」涌现了？但这个现象也可以有另一个解释：  (&#x539F;&#x7406; 1)a&#xA0;&#x8DDF;&#xA0;b&#xA0;&#x8BED;&#x4E49;&#x8D8A;&#x76F8;&#x8FD1;&#xA0;&#x21D2;d(a,b)&#xA0;&#x8DDD;&#x79BB;&#x8D8A;&#x77ED;" role="presentation">(原理 1)a 跟 b 语义越相近 ⇒d(a,b) 距离越短a \mbox{ 跟 } b \mbox{ 语义越相近 } \Rightarrow d(a,b) \mbox{ 距离越短} \tag{原理 1} 而由于（右图）那些距离之间的关系，这个方格被逼成为 <strong>平行四边形</strong> 的形状。 所以，「方向性」其实是 距离 根据（原理1）而产生的「副现象」。$

(原理1) 成立的背后原因可能是这样的：机器学习 的原理是基于「泛化」，即在 原空间上 <strong>邻近</strong> 的点，通常被映射到 目标空间上 <strong>邻近</strong>的点。由于 神经网络是 <strong>连续</strong> 映射，它将邻近的点映射到同一点是比较容易的，但如下图那种例外的情况就比较难，需要动用较多的计算资源（即权重）：

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_d0d4d393c12c.jpg)

因此，神经网络 完全有理由 在 hidden representation 里，<strong>将意义相近的词映射到邻近的点</strong>。所以（原理1）成立。

但如果我们将此 embedding 视为 <strong>向量空间</strong>，则有些操作无法解释。 向量空间的严格定义是：

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_788bd71f99ee.jpg)

特别地，标量乘法，例如 0.5 \vec{\mbox{ man}} \mbox{ 或 } 0.7 \vec{\mbox{ (I ∙ love ∙ you)}}  这样的东西的意义很难解释。 而且，在 metric embedding 里， 0.5 \vec{\mbox{ man}} 完全有可能跟另一个意义不相干的 词向量「相撞」，而如果要避免这种 相撞，每个意义都需要有它自己的维度 (dimension) ; 这似乎不切实际，也失去了 embedding 的维数少的优势。

在抽象代数里，习惯将“algebra”定义为一种 vector space，所以我一直在想，会不会 逻辑 algebra 就是深度学习里的 vector embedding？但越想越觉得不对头，似乎接受它是 metric embedding 就容易很多。

另外一个问题是：embedding 里面的 <strong>距离</strong> 究竟有什么意义？ 根据（原理1），它纯粹就是 <strong>语义相似性</strong> 的一种量度。但我们可以 embed 词语，也可以 embed 句子，而 句子类似于“thoughts”即「思维」。 那么 <strong>思维空间</strong> 的 embedding 其实也是根据「意义相似性」量度的。 这里有个问题是：某些句子，如果某个词用类似的词换掉，其意思可能相差很远，而这种情况是所谓“idiomatic usage”，它是「约定俗成」的例外情况。 如果不考虑 idioms，则语言会完全符合 组合性 (compositionality).

我曾经把 思维空间 的距离 设想为 推导距离 (inference distance), 但这也有问题。 例如「单身汉」的推导，它涉及一个 <strong>逻辑规则</strong>的应用（左图），严格来说它是一个 proof tree，它不能转化为简单的 graph（右图），而 右图的距离的定义是不明确的：

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_1e895e4fc62c.jpg)

Inference distance 其实是很难计算的，它涉及寻找最短的 proof，这是 Kolmogorov complexity.  它只能被近似，但没有算法可以保证将它计算出来。Anyway，metric embedding 绕过了这一麻烦。

#### Embedding 空间 是连续的 还是 离散的？

当然，<strong>符号</strong> 是离散的东西，我们不可能将「爱」的符号连续地变成「恨」的符号。 但我觉得可以将嵌入空间看成是 连续空间，理由是： 当我们 微扰 (perturb) hidden representation 的时候，系统仍然会输出某些符号。 情形就像某种 Voronoi tessellation（左图），它不是连续变化的，在边界处会出现 <strong>突变</strong>：

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_7026eb957595.jpg)

而它实际上分割的方式，不一定严格符合 Voronoi 的定义，而是 implementation dependent 的。 例如 Transformer 输出的是词的 <strong>概率</strong>，那么词的边界就是根据概率定义的，那种边界是模糊的（右图）。

#### 逻辑 推理算子 与 Looped Transformer

逻辑推理算子 (<strong>consequence operator</strong>)，符号是 A \vdash B , 意思是从一些逻辑命题的集合 A（前提）推导出新的命题 B（结论）。 其实 LLM 例如 GPT 也可以看成是逻辑推理：它从 prompt 推导出新的句子。 

每个句子可以看成是 <strong>思维空间</strong> 中的一点，推理算子 是一个<strong>函数映射</strong>，它从已知的命题 映射到 新的命题。 其实 LLM/GPT 也是这种函数映射的一个特例。

我最近提出，如果将 LLM 的百多层的 Transformers 变成循环的 <strong>Looped Transformer</strong>，资讯的压缩会更有效，甚至可以解决 hallucination 的问题（这个理论详见另文）。

Looped Transformer 是神经网络，也是函数映射，它是 A \vdash_{\mathsf{KB}} B 的形式，它不断用 知识库 (KB = knowledge base) 内的逻辑规则 做推理，而特点是这个 知识库 的规则是 <strong>重复使用</strong>的。

函数映射 的形式是 \vdash: U \rightarrow U 其中 U 就是我们上述的 embedding 空间，或「思维空间」。

很自然会联想到 <strong>Brouwer 不动点定理</strong>：Any continuous function from a compact space to itself has a fixed point.  然后 Schauder 将它推广到 无限维的 Banach 空间。在最优化理论里，一个流行的版本是：Every non-expansive self-mapping of a non-empty, closed, convex, bounded subset of a Banach space has a fixed point.

以逻辑推理算子 \vdash_{\mathsf{KB}} 来说，它的 fixed point 就是：根据已知的事实，凭我们所有的知识 = 知识库里的所有逻辑规则，我们可以做出的所有推论。 当所有推论都已经做出之后，状态不再改变，所以 f(x^*) = x^*.

有时候，推理的过程可以是无限的。例如 n \mbox{ 是偶数} \Rightarrow n + 2 \mbox{ 是偶数} ，那么 2, 4, 6, 8, .... 都是偶数，直到无穷。 这些命题如要挤进一个 bounded 的空间内，除非它们之间的距离不断缩小。 但我暂时不知道可以怎样定义这种距离。

还有一个条件是 <strong>convex</strong>.  Convex set 的定义是：对集合内的任意点 x，y，连接它们的直线也必需属于这集合（左图）。 根据我们上面对 Voronoi tesselation 的论述，这是可以满足的。 

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_165d248bff13.jpg)

当一个序列收敛到 x^* , 直觉上是像（右图）的样子。 但 \vdash_{\mathsf{KB}} 映射 不断给出 思维空间里的新的点子，这跟我们的直观好像不符？理由是： \vdash_{\mathsf{KB}} 是一种 <strong>set-valued mapping</strong>, 它不同于一般的函数，除非我们在 power set 的图像里想象它的样子。 Set-valued maps 在经济学里有应用，它的不动点定理很早就确立了。

所以结论是： Looped Transformer 符合 逻辑推理算子 的特性。 我估计 Looped Transformer 可以成功建立 AGI 模型。
