本文首发于 Mindverse Research 公众号，编辑：朱思嘉**深度学习大牛 Yoshua Bengio 曾以*《From System 1 Deep Learning to System 2 Deep Learning》*为题在 NeuIPS 2019 上做了特邀报告。当时他指出深度学习聚焦于类似 System1 的直觉式系统的有限性，并点明了未来类似 System2 的分析式系统的发展潜能。随着近些年来技术与模型的发展，如今的 AI chatbot 是否会表现出类似人类的双系统加工特征？又是什么在影响其选择不同系统的加工方式？几位学者使用机器心理学的方法对 LLM 的「认知过程」进行了研究， 通过改编的认知反射测试和语义错觉范式证明了最新的 LLM 中可以存在类似 System2 的加工方式，并且指出这种认知能力以及与之相关的涌现属性不仅与 LLM 的规模相关。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_0456b53fb056.jpg)

原文链接：https://arxiv.org/ftp/arxiv/papers/.05206.pdf

大型语言模型（LLM）的应用不断拓宽，因此对其内在推理和决策机制的了解变得十分迫切。最近研究表明，随着 LLM 的复杂性不断增加，它们表现出了许多设计者未曾预想的新能力，比如生成代码、解决数学问题、从示例中学习、解决心理理论任务等等。这篇文章试图通过探索其中一种涌现的能力（推理能力）来揭示 LLM 错综复杂的认知过程。

认知科学的双加工理论提出，人类认知过程可以被大致分为系统 1（下文简称 S1<strong>）和系统 2（下文简称</strong>S2<strong>）两种加工模式。</strong>S1 的加工是一种直觉式的加工<strong>，快速、自动、通常涉及启发式，无需有意识的努力即可快速做出判断和决策。S1 对于日常生活至关重要，它可以节省人类认知资源以快速决策。另一方面，</strong>S2 的加工是一种分析式的加工**，通常用于逻辑推理、批判性思维和解决问题等、需要决策者付出有意识的努力。S2 加工速度较慢且更加耗费认知资源，但它们也更准确且不易受各种偏差影响。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_f20eea254644.jpg)

从表面上看，现在 LLM 的加工方式更符合 S1：输入文本由连续的神经元层加工，产生所有可能的单一标记（单词）补全的概率分布。这个过程是自动、单向的，并且包含每个连续预测单词通过神经网络的单波传播。由于<strong>当下的 LLM 缺乏合适的认知架构</strong>，因此很难对其初始的假设进行验证，也不利于检验替代方案、反馈循环和其他通常与 S2 过程相关的认知策略。

然而，<strong>大量证据表明，LLM 可以像人类一样同时拥有 S1 和 S2 认知过程。</strong>生成每个连续单词时，LLM 都会重新读取上下文，包括原始输入（如用户提供的任务）以及迄今为止生成的单词。因此，上下文可以作为外部短时记忆，被 LLM 用以思想链推理、重新检查起始假设、估计部分解决方案或测试替代方法。类似于人们使用记事本解决数学问题或撰写文章来发展他们的论点。


本文以推理和决策心理学研究为基础，探索了 LLM 的 S1 和 S2 过程。研究任务改编自两种经典的范式：认知反射测试<strong>（cognitive reflection test,</strong>CRT）和语义错觉任务**（semantic illusion）。CRT 包含三种看似简单的数学任务类型，以触发直觉（但不正确）的 S1 响应：类型 1 ，使用「超过」等词语诱导回答者做出简单的计算而非建立复杂的方程，如：*「球棒和球共支付 1.1 美元，球棒单价超过棒球 1 美元，那么一颗球多少钱？」*；类型 2 利用了人们捕获数量关系的倾向，例如：*「两台机器在在两分钟内制造了2个部件，五台机器制造5个部件需要多久」*； 类型 3 诱导参与者将指数过程视为线性过程，例如：*「池中睡莲每天翻倍，长满池塘需要48天，长满池塘的一半需要多少天？」*。正确解决 CRT 任务需要进行分析式的 S2 推理或拥有完善的 S1 直觉。语义错觉是包含错误前提的问题，旨在触发直觉但不正确的 S1 响应。例如，著名的摩西错觉中，人们被询问「摩西从每种动物中带了几只上方舟」，大多数人会回答是「2只」，鲜少有人指出把动物带上方舟的是诺亚而不是摩西。

过去研究强调，LLM 在 CRT 任务中往往会陷入与人类相同的陷阱。在这里，研究者表明 LLM 也可以参与类似于 S2 分析式的推理过程。此外，随着 LLM 表现的提高，其类似 S1 的单词生成过程会变得足够敏锐，可以防止落入任务中的陷阱。

本研究还解决了过去研究的一些局限性：（1）过去的研究集中在单一模型（GPT-3）上，但本次调查了一系列不同规模和复杂性模型的推理能力；（2）由于解决 CRT 任务需要数学能力，LLM 的表现可能会受到其数学能力的限制。为了解决这个问题，研究者用不依赖数学能力的语义错觉任务进行了补充；（3）过去的研究使用原版 CRT 任务，这些数据可能存在于 LLM 的训练数据中，因此研究者改编了实验材料。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_7dc839417523.jpg)

实验材料示例![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_b927c34f2d9f.jpg)


3 种类型的 CRT 任务和语义错觉任务（具体见原文补充材料）被分配给 GPT 系列模型（GPT-1 ~ GPT-4）。为了最大限度地减少模型响应的方差，提高结果可复制性，研究中将 temperature 参数设置为 0、生成长度设置为 100 tokens（可根据需求进行延长）。LLM 的回答由人工进行标注与评估。 

500 名人类参与者也接受了同样的任务，每人随机完成 4 个任务（每种类型各一个）。人类参与者的结果显示，本文改编的 CRT 和语义错觉范式与经典范式的难度相当，CRT 的正确率和语义错觉的直觉反应率与前人研究结果无显著差异。

### Study 1：认知反射测试（CRT）

我们以下面这个具体任务为例，解释 LLM 在 CRT 任务中的表现：

*CRT-Type3 #14*：山洞中有一群蝙蝠，数量每天翻一番。如果 60 天后蝙蝠就会填满洞穴，那么洞穴被蝙蝠填满一半需要多少天？该问题的正确答案是 59 天，但其简单的表象诱使回答者在直觉上做出 30 天的反应。回答者（LLM 和人类）在这类问题上的反应被分为三类：正确反应（绿色条柱）、直觉反应（蓝色条柱）和非典型反应（灰色条柱，直觉反应外所有错误反应）。结果如下图所示，黑点标记为 LLM 回答中存在思维链（CoT）推理的情况。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_298523c168a6.jpg)

上图中呈现了四个明显的趋势：（1）早期和规模较小的 LLM 的大多数反应被归类为非典型反应**：包括回避回答（如 GPT-1：「很多天」）、未能理解任务（如 GPT-2XL：「需要 60 天才能扩大一倍」）、不正确也不属于直觉回答（如 GPT-3-babbage：「大约需要 10 天，洞穴才能被蝙蝠填满一半」）。 此外，虽然 GPT-3-babbage 和 GPT-3-curie 的响应中有 15% 被归类为正确反应，但它们似乎是偶然的。因为对于 CRT 的类型 2 来说，只需重复提示中最常提到的数字就可以解决问题，而这些模型在任务中表现出了这种简单的策略。


（2）当模型规模变大、理解任务的能力增强，直觉反应会被非典型反应替代，例如 GPT-3-davinci 系列，其中直觉反应的比例远高于在人类中观察到的比例**。

在人类中，直觉反应既可以被解释为 S1 的认知结果（S2 没有参与），也可以源于 S2 加工后的错误。而 LLM 做出直觉反应的原因更加清晰：由于当下的 LLM 缺乏参与 S2 所需的内置认知架构，因此他们的直觉反应只能源于类似 S1 的过程。

重要的是，上述 LLM 做出直觉反应的倾向不太可能源自其数学技能的不足：首先，研究表明这些 LLM 可以解决基本的数学问题；其次，要对 CRT 类型 1 和类型 3 的任务做出直觉反应也需要求解一个简单的方程（例如，60的一半是多少）；最后，如研究 3 所示，通过提供训练示例，GPT-3-davinci-003 的性能可以得到显著提高。


（3）随着 ChatGPT 的出现，LLM 强烈的直觉反应倾向开始趋于停止。**ChatGPT-3.5 的正确回答比例为 59%，GPT-4 的正确回答比例为 96%，远高于 GPT-3-davinci-003 的 5% 和人类的 38%。同时，直觉反应趋势显著下降：ChatGPT-3.5 为 15%，GPT-4 为 0%，而 GPT-3-davinci-003 为 80%，人类为 55%。


（4）仔细观察 ChatGPT 模型的响应就会发现，模型性能的提高伴随着一种新的响应方式。ChatGPT 之前的 LLM 使用简单的短语或单句进行回复，但 ChatGPT-3.5  97% 的回复和 GPT-4 85% 的回复包含了某种思想链推理（CoT）的形式**（上图中的黑点），具体示例如下图所示：

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_f49663151b05.jpg)

如前文所述，ChatGPT 和目前其他的大语言模型在生成下一个单词时并没有真正的深思熟虑。但每次生成时，LLM 都会重新读取任务和迄今为止生成的响应，将类似 S1 的单词生成结合到类似于 S2 的过程中，生成解决任务所需的策略，将任务分解为更容易处理的子任务，然后逐一解决。这类似于人类借助笔记本解决数学任务，这样就不需要在自己的短时记忆中加工它们。<strong>在研究 2 中，研究者将展示 CoT 不仅类似于 S2 过程，而且也可以充当 S2 过程。</strong>**

### Study 2：思维链推理如何影响 CRT 表现

研究 1 的结果表明，LLM 在 CRT 任务上正确表现的突然提升伴随着思维链（CoT）推理的出现与运用。那么<strong>指导 LLM 进行 CoT 推理是否真的可以提高 LLM 解决推理任务的能力呢</strong>？

为了回答这个问题，研究者首先通过在问题上添加后缀提示 GPT-3-davinci-003 进行 CoT 推理：*「请用代数解决这个问题」*。该操作成功地将 CoT 的比例从研究 1 中的 0% 增加到 100%。该模型似乎设计并执行了任务解决策略，在某些情况下，成功将正确答案的比例从 5% 提高到 28%；但很多时候，会出现设计或执行不当，导致非典型反应从 15% 增加到 43%。不过，最重要的是，<strong>提示 LLM 进行 CoT 推理显著降低了模型陷入问题陷阱的倾向</strong>，直觉反应比例从 80% 下降到 29%。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_36844405f930.jpg)

与此同时，研究者还通过在问题上添加后缀来阻止 ChatGPT 和 GPT-4 进行 CoT 推理：*「请提供尽可能短的答案（如『2美元』或『1周』），不要解释你的推理」*。该操作成功地将 ChatGPT-3.5 的 CoT 响应比例从 97% 下降到 0%，GPT-4 从 84% 降至 0%。然而，<strong>ChatGPT-3.5 的正确比例没有显著变化</strong>；<strong>GPT-4 的直觉反应比例从 0% 增加到 10%</strong>（统计显著，*p 链式推理就解决了 24% 的 CRT 任务。 研究 3 更详细地探讨了这一现象。


### Study 3：通过示例改善 LLM 直觉反应

研究 2 表明，ChatGPT 之后的 LLM 即使不参与 CoT 推理（S2），也可以避免直觉陷阱并正确解决它们。对于人类来说，这源自先前接触过 CRT 或类似任务发展的发达直觉（尽管这种效应的持久性和大小存在争议）。 而本研究结果表明这结论同样适用于 LLM。与过去的结果一致，<strong>LLM （即使从单个示例中也）可以学习</strong>。

由于 ChatGPT 模型似乎已经拥有了完善的直觉，研究者尝试改进 GPT-3-davinci-003 中类似 S1 的响应。他们在向其提供 CRT 任务之前，会提供 0~49 个相同类型的其他任务，并附有正确的解决方案。同一类型的 CRT 任务在语义上非常相似，使模型能够开发类似于 ChatGPT 模型的 S1 直觉。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_1a34b7df9c70.jpg)

如图 2 的结果，GPT-3-davinci-003 正确（而非直觉）回答的能力随着示例的增加而增强。 在 CRT 类型 2 任务中观察到最快的增益。由于解决 CRT 类型 3 的问题，需要用总时间减去1个单位，相对更加复杂：经过 7 个训练示例后，准确率从 12% 提高到 92%。CRT 类型 1 任务的正确答案等于 (total price - known price) / 2。 即使在这样复杂的情况下，在 30 个示例后，模型的准确率也从 0% 提高到约 78%。


### Study 4：语义错觉任务

研究 1~3 中使用的 CRT 任务在很大程度上依赖于数学技能，并且在语义上高度统一。为了确保结果能够推广到 CRT 任务之外，研究者检查了 LLM 在语义更加多样化的任务（语义错觉）上的表现。每个语义错觉任务中包含一个伪装的错误，旨在触发直觉但不正确的 S1 响应。与 CRT 任务不同，语义错觉不需要数学技能，而是依赖参与者的常识。

以下方为例：

*语义错觉任务 #47*：位于马德里的著名教堂圣家堂（la Sagrada Familia）是由哪位著名艺术家设计的？语义错觉任务旨在触发 S1 的直觉反应「安东尼·高迪」（Antoni Gaudí）。在回答者做出直觉回答后，会被进一步追问基础知识：「圣家堂位于哪里？」。只有当回答者同时具备常识基础（知道圣家堂位于巴塞罗那），但依旧给出直觉反应（安东尼·高迪），这样的回答才被归类于直觉反应；未满足上述两个条件的错误反应被归类为非典型反应。因此,语义错觉中的非典型反应分为「常识缺失」（如 GPT-3-babbage 回应：弗朗西斯科·戈雅）和「无意义反应」（如 GPT-1 回应：旧金山教堂）。只有认为问题本身有误的回应才被归类为正确（如 GPT-4 回答：圣家堂实际上位于巴塞罗那，而不是马德里，是由著名的西班牙建筑师安东尼·高迪设计的）

如下图，语义错觉的结果和 CRT 任务中的结果模式类似。较早和较小型的 LLM（GPT-3-babbage 及之前）的大多数回答都是非典型的（灰条），因为他们难以理解问题或缺乏必要的知识。 随着 LLM 规模和复杂性的增长，非典型反应的比例下降，开始被直觉反应（蓝条）取代。而 ChatGPT 的出现大大地改变了这种趋势：正确反应急速上升。因此，和前文一样，即使 LLM 的单词生成过程中没有深思熟虑，这种类似 S1 的过程也很适合检测语义错觉中包含的错误前提。

![](/images/collections/0.raw/zhihu/LLM%26SD/asset/img_4ee74d70dba0.jpg)

### Study 5：提高语义错觉任务表现

研究 2 和 3 的结果表明，LLM 在 CRT 任务中的错误比例可以通过提示其更仔细地检查任务并提供类似任务的正确反应示例来减少。研究 5 在语义错觉的背景下复制了这些结果。

研究者首先为每个语义错觉任务提示添加后缀*「仔细思考并检查问题是否存在无效假设」*，结果显示 GPT-3-davinci-003 正确反应比例增加了三倍（如上图 研究 5 部分，从研究 4 中的 18% 增加到 54%），而直觉反应比例从 72% 下降到 28%。

接下来，研究者在每个语义错觉任务前提供 0-49 个附有正确解决方案的类似任务示例，正确比例随提供示例数的提升如下图曲线所示。

总之，<strong>LLM 在语义错觉任务上的表现与 CRT 中观察到的表现如出一辙：早期模型难以理解任务，后来的模型逐渐表现出高于人类的直觉反应倾向，而 ChatGPT 之后的最新模型则表现出了超越人类可以避免语义幻觉的能力。 此外，通过提示仔细检查和提供示例可以显着提高 LLM 的表现。</strong>

### 讨论与小结

本研究使用通常用以研究人类认知过程的 CRT 任务和语义错觉任务来研究 LLM 的推理过程。结果揭示了三种主要模式：

（1）随着 LLM 规模的扩大和理解任务能力的增强，它们往往会落入任务中的陷阱并做出直觉反应（类似于人类自动快速的 S1 过程）。<strong>作者认为 LLM 具备足够的数学能力却依旧做出直觉反应的原因是 LLM 缺乏参与 S2 加工所需的认知架构</strong>。因此，在缺乏发达的直觉或明确的 CoT 推理的情况下，LLM 特别容易陷入任务中的陷阱。

（2）ChatGPT 出现后，直觉反应趋势突然改变，错误的直觉反应急速减少，正确反应远超过人类的相应比例。ChatGPT 对 CRT 任务的大部分响应都涉及 CoT 推理，其中 LLM 制定解决策略、检查起始假设、估算解决方案并检验替代方法。这表明 <strong>LLM 可以使用其输入-输出的上下文窗口进行类似 S2 的推理，类似于人们使用记事本解决数学问题或撰写论文来发展他们的论点</strong>。研究 2 的结果进一步证实，CoT 推理可以提高 LLM 的表现。

（3）进一步分析表明，就算 ChatGPT 之后的模型没有进行 CoT 推理，也可以成功解决 CRT 任务和语义错觉任务。这些结果表明 <strong>ChatGPT 之后的模型具有「完善的直觉」，使它们能够解决 CRT 任务和语义错觉任务，而无需参与类似 S2 的过程</strong>。并且只要提示较早的模型（例如：GPT-3-davinci-003）进行 CoT 推理并提供正确解决方案的示例，就可以显着提高其在这两种任务上的表现。


在人类中，CRT 和语义错觉中的表现是无偏见、反思式的理性决策能力以及整体认知能力的良好预测指标。因此，LLM 在这两种任务上的能力理应随着其综合能力的提升而提升。但本研究中发现 LLM 在这两项任务上的增长比其整体能力的增长显得更为急剧**。由于不了解 OpenAI 的训练过程和技术规范，研究者只能给出以下几种猜测：（1）能力的突增不仅由于模型的规模造成：具有相似规模的 ChatGPT-3.5-turbo 和 text-davinci-003 在表现上大不相同；（2）这种转变可能与人类反馈强化学习（RLHF）方法有关；（3）ChatGPT 之后的模型可能在训练过程中接触过足够多的类似 CRT 的任务（在语义上与这次的题目高度相似），因此可以做出正确的反应，但是这很难解释 LLM 在语义错觉任务中的表现（这些任务更加不规则且多样化，且由研究者自己定制）。


除了分析 LLM 在推理任务上的表现之外，我们还可以从一种规范的视角（a normative perspective）来讨论 LLM 是否需要直觉决策现象<strong>。 在认知科学文献中，研究人员强调，直觉错误的概念依赖于逻辑和统计学的规范概念，这可能不适合于现实世界的情况。现实世界中，决策过程应该在一种「生态理性」（ecological rationality）的意义上进行评估，即需要考虑决策过程与决策发生环境结构的契合程度。在这种情况下，CRT 任务以及语义错觉任务创造了一种「敌对的环境」：特意地去误导参与者。那么，关于语义错觉任务，人们就可以问：</strong>LLM 是否应该顺应对话流程，「忽略」小错误，而不是纠正那些不正确的前提？**在人际对话中，交流者之间快速切换需要高度的沟通协调，避免对话的中断，这就不允许发言者逐字分析、检查语义结构。如果 LLM 有相似的表现，可能意味着它们想要促进流畅的沟通，一旦这些语言模型成为社会中的自然对话者，这可能就会成为一种重要的能力。 另一方面，「幻觉」输出、事实不正确和错误信息危害又是 LLM 的一个主要问题。除了关于评估和直觉「错误」的规范性讨论之外，值得注意的是，即使在敌对的环境（例如 CRT 或语义错觉任务）中，ChatGPT 和 GPT-4 等最先进的 LLM 也可以（在大多数情况下）不犯错误，表明了它们非凡的推理能力可能在本研究环境以外的领域产生影响。

LLM 的发展提高了其自身的能力，也降低了人们预测其属性和行为的能力，使得人们通过架构和超参的视角来研究 LLM 越来越困难。受启发于另一种黑盒（人类心智）的研究方法，现在，LLM 研究人员可以借用经典的心理测试和实验来对 LLM 多种「认知过程」进行评估与探索，这将为 LLM 的多种能力提供洞见。
