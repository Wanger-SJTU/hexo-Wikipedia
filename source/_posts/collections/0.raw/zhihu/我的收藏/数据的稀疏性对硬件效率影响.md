前面几篇文章已经从overhead分摊、数据精度、内存分层及复用的角度讲了如何优化使得硬件的能耗降低。本小篇是从无效操作的角度，所谓的无效操作指的是就稀疏性，也就是如果存在大量的0的时候，我们还计算这些0*X或者0+X的时候，存在一种资源浪费。

本文主要是从粗颗粒度稀疏性处理、细颗粒度稀疏性处理及稀疏矩阵的压缩存储这三个角度来说。需要注意的是，这些方法可能更多的处理矩阵，放在神经网络结构上就是以线性层为基础的网络结构。

### 1. 什么是矩阵稀疏性

![](/images/collections/0.raw/zhihu/%E6%88%91%E7%9A%84%E6%94%B6%E8%97%8F/asset/img_ec221d067702.jpg)


稀疏其实就是矩阵存在大量的0或者很小的值。比如上图左边的数据要和右边的权重进行点乘，数据和权重都有稀疏性。

数据的稀疏更多是来自于类似于ReLU这样的激活函数。ReLU(x)=Max(0, x)，这样会导致大量的数据变为0，这也是非线性关系的一个来源。

而权重的稀疏最开始是来自于一些归一化形成的较小的权重，然后在Pruning的过程中形成的大量为0的稀疏性。

还有一个块稀疏就是像上图这种一个m*m的块上全都是0的样子。

### 2. 粗颗粒度稀疏块处理

神经网络的加速器都是并行计算的，也就是同一个时钟内会进行多个并行的MAC操作。粗颗粒度稀疏块处理上，我们是假设在某个大块的MAC操作由于稀疏性的原因是可以略过的。

而在我们假设有一个256*256的矩阵权重，如果硬件每时钟可以进行8*8=64个乘加运算，那么这个矩阵按这个块进行划分，就会有64*64=4096个块。如果这4096个块都有非0权重的话，那就不说了，但是如果存在有大的块存在全0，是可以略过的，比如如果有1000个块中存在全0，那么可以加速4096/（4096-1000）倍的快速。

当然这也存在一定代价，是需要加一个小的Bitmap，也就是64*64的Bitmap用0和1来标定是否是全0，这也存在一定的overhead的增加。

### 3. 细颗粒度稀疏块处理

细颗粒度的稀疏处理也是近几年才引入NVIDIA的Tesnsor Cores中的。这个细颗粒度的稀疏处理有点像Prune的感觉。它有一个要求，就是比如在一个2*2的小矩阵块中，强制会要求有两个值为0。实现的方式就是先进行训练，训练完后在每一个2*2的块中，把绝对值最小的两个元素强制为0，进行进一步的重新训练。这个也叫2:4稀疏模式。

细粒度稀疏的加速并非来自减少乘加操作（MAC）的总次数，而是通过以下方式实现加速

<strong>显存带宽减半（关键加速点）</strong>

压缩存储：2:4稀疏模式下，每个2x2块仅需存储2个非零值（原需4个值），显存占用直接减半。例如：一个2x2块 [0.0, 1.0, -0.5, 0.0] → 只存储非零值 [1.0, -0.5] 和2bit掩码 [0,1,1,0]。

带宽优势：从显存读取权重数据时，传输量减少50%，显著降低IO延迟（尤其是显存带宽受限的场景）。

<strong>计算效率优化</strong>

零值跳过：虽然Tensor Core的矩阵乘法单元（如WMMA API）仍需处理完整矩阵，但硬件可通过掩码动态跳过零值计算：例如：在计算 A * B 时，若 B 的某些位置为零，可跳过对应乘加操作（减少实际运算能量，但可能不减少时钟周期）。

线程级并行优化：稀疏数据允许GPU线程更高效地分配计算任务（例如，合并内存访问）。

<strong>硬件指令优化</strong>

专用稀疏指令：NVIDIA的Tensor Core可能针对2:4稀疏模式优化了指令集（如mma.sp.sync.aligned），直接操作压缩后的数据格式，减少解码开销。

### 4. 稀疏矩阵的压缩存储

稀疏矩阵的压缩存储（如CSC、CSR、COO等格式）的核心思想就是：仅记录非零元素的值（value）及其位置（行和列），而零元素直接被忽略。不同的稀疏格式只是存储这些信息的排列方式不同，以适应不同的计算需求（如行优先访问、列优先访问等）。

比如CSC格式，看似只是“节省存储空间”，但实际上它通过 减少数据搬运量 和 跳过无效计算 来间接降低能耗并加速推理。

在节省能耗方面，主要是通过减少数据搬运和跳过无效计算来实现的。在AI芯片（如GPU）中，数据搬运（从显存到计算单元）的能耗远高于计算本身。CSC格式仅搬运非零值（values）和位置信息（row_indices和col_ptrs）。若矩阵稀疏度为90%，CSC可减少90%的数据搬运，直接降低显存访问能耗。而计算 0 * x 或 0 + x 是无效操作，但仍需消耗时钟周期和功耗。在稀疏矩阵乘法（SpMV）中，CSC格式显式标记非零值位置，硬件可动态跳过零值计算。若稀疏度为90%，理论计算能耗减少90%。

对于加速推理，主要是通过内存带宽瓶颈的缓解。在大型矩阵乘法（如神经网络推理）中，计算速度常受限于内存带宽（即数据搬运速度，而非算力）。对于稠密矩阵，搬运 1000x1000 的FP32矩阵需 4 MB。而CSC格式（90%稀疏），仅需 0.4 MB（非零值）+ 元数据（约 0.1 MB），总数据量减少87.5%。稀疏矩阵的压缩存储减少了数据量，使得相同时间内可搬运更多有效数据。
