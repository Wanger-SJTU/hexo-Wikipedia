软件自适应性趋势

赵俊民
​
探索技术

收录于 · 模式思维

5 人赞同了该文章

一个软件体如果类比一个生物的话，是否可具备自主学习与持续进化能力的“生命体”。

现在传统软件的演进和变化都是工程师完成的，工程师不断的修改，增加特性，软件就持续变化。现在通过OTA或者网上更新的方式，软件也可以进行更新。

现在有一种自演化自适应的agent应用，可以在运行过程中自动优化prompt，产生子agent，甚至调整agent结构，自己优化自己。

软件自己修改自己，有点类似智慧生命的味道，也有一些元能力的能力。以前在手机软件上会有一些根据用户习惯调整自己的算法，如最近应用使用推荐或者预加载，一般根据贝叶斯算法就可以做一些推测。

现在AI的能力，给软件赋予了更多的自适应能力。本身AI可以自动生成代码，代码可以被编译或者虚拟机进行解释执行，甚至有些AI根据一些描述，还可以自动产生一些app或者小程序来满足一些确定性需求。

https://arxiv.org/abs/2509.01245

Towards Agentic OS: An LLM Agent Framework for Linux Schedulers

最近ML4SYSTEM有个文章，介绍了自动profile负载之后，用大模型去根据eBPF的sched_ext框架产生一个适合的调度器，然后加载运行。这个就构成一个根据应用负载自动去适应优化的路径。

另外一个工作，主要是自己调整自己的一个AI探索

另外一个工作，可以参考从千问灵光 App 看生成式 UI 技术的发展

https://www.chaspark.com/#/hotspots/1218059469105512448

生成式 UI 的崛起，标志着确定性交互范式正向“意图驱动”范式转移。在生成式 UI 的框架中，界面不再是“静态资产的集合”，而是“流动性组件的集合”。应用不再依赖预先定义的界面，而是基于大语言模型对用户自然语言指令、当前上下文环境及历史行为模式的理解，动态生成最适合当前任务的界面组件。我觉得这篇文章说的非常好，是未来一个AIOS关键技术之一。

软件自适应性是未来AIOS关键特征，其实荣耀荣耀Magic8：一部“自进化”的AI新物种也提出过这个，不过思考的不彻底，未来在大模型/agent，端云结合的框架下，可能会出现越来越适应性，越演化的软件。
