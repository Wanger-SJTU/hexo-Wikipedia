ChatGPT引发的讨论还是比较多的，我也逐渐发现大家对于LLM的理解、期待以及批评都是存在比较大的偏差的，前一阵我也写了我的一些理解，[mackler：自举：ChatGPT的AGI之路](https://zhuanlan.zhihu.com/p/623585915)，不过缺乏观点的碰撞，也很难抛砖引玉，今天就再写一篇来点更多的观点的碰撞，关于LLM的理解。

最近在知乎上刷到一个贴子：[周昕宇：压缩下一个 token 通向超过人类的智能](https://zhuanlan.zhihu.com/p/619511222)，这个观点在知乎上还有不少类似观点的贴子。核心思想大致为：模型通过压缩海量数据，压缩率越高，越接近数据背后真正的规律，也就越接近真正的智能。

这个观点怎么说呢，有点古墓派。这个观点是对深度学习的理解，从Hinton的DBN开始就是表示学习，用玻尔兹曼分布逐层学数据的压缩表示，这个观点套用到DBN上也是非常准确的，运用到过去的深度学习模型上也都是合理的，但这个观点不是对LLM的理解。

有人可能会说了，LLM不是深度学习吗？当然是，但这就得提起ChatGPT火起来之后一个很高频的词“涌现”了，“涌现”这个词来源于凝聚态物理的著名论文《More is Different》，我在很早之前的一个贴子里（[mackler：类脑计算的困境和出路（2）](https://zhuanlan.zhihu.com/p/383063637)）也阐述过涌现性视角对于深度学习和AGI的重要性，深度学习是图灵机之上的涌现，而AGI需要在深度学习基础上进一步涌现，只是这个涌现维度，我当时所期望的方向是模型结构层面的复杂性，而现在LLM实现了这个深度学习基础上的涌现，这里直接摘录一段那个贴子里的话

> More is Different这篇文章指出，认识世界不止包含每个基本组件的规律，更包含了组件之间的组织形式。当体系的复杂性增加到一定程度，会涌现出与基本组件规律无关的新规律，而这部分规律也是认识世界的一部分。
更具体一点，学科X的基本实体遵循学科Y的定律并不意味着学科X仅仅是Y的应用，X具有全新的规律。例如固体/多体物理基于粒子物理，化学基于多体物理，分子生物学又基于化学，细胞生物学进一步基于分子生物学，……，心理学基于生理学，社会科学又基于心理学。层级隔的越远，这种规律的独立性体现得越直观，毕竟社会科学的规律靠研究粒子物理怕是永远也得不出来。这就是层级的体现，每一层涌现的新规律都独立于下面层级的规律。这种独立性的另一个体现在于，即使我们更换了支撑底层系统的构成方式与规律，只要高层级规律所依赖的基本抽象不变，高层级的很多规律仍然会成立。
深度学习和图灵机的关系也前面说到的不同层级一样：深度学习基于图灵机，但深度学习具有独立于图灵机的能力

所以，LLM是一种深度学习模型，正如深度学习也是一种图灵机程序一样。“智能即压缩”与“智能即计算”一样，正确，但不是对LLM的理解。

ChatGPT相比深度学习，最大的突破在于In Context Learning的能力，这也是其one-shot或者zero-shot的能力来源，同样也不是一般意义上的深度学习模型所具备的能力。而“智能即压缩”所阐述的能力更多是通过SGD训练得到的压缩表示。

有人可能会说了，In Context Learning也不过是从海量的语言语料下学习到的条件概率分布罢了，是压缩学到的高级表示，甚至可能是某种人类所不能理解的更高压缩率更高级的智能。

压缩这个视角，总体来讲，还是一种还原论的视角，把海量纷繁的数据压缩到少量简单规律上，把越来越多的规律统一到越来越少的更基础的规律之上，从而实现更高的压缩率，这个规律可能比人类总结得还好精简。这可以解释LLM在世界模型方面的海量记忆能力，但智能更广阔的部分在于恰恰在于构造。还原论不是智能的全部，还有构造的能力。举个更具体的例子，从牛顿的苹果和天空中的星星月亮的运行数据，可以压缩出万有引力和牛顿运动三定律，但压缩不出汽车、火箭的设计，也压缩不出计算机、深度学习和LLM的设计。而ChatGPT所呈现的In Context Learning的逻辑能力恰恰是构造能力的关键。

有人可能又会说了，我测试了一下让ChatGPT帮我设计东西，它也只会瞎糊弄。

哎，这又涉及到我今天想思维碰撞的第二个点了。ChatGPT该怎么用？之前没拿到国产LLM的测试资格，一直在网上看别人测评，整体评价非常乐观，觉得国产LLM和GPT3.5差距不算太大，和GPT4有一定差距。这个其实非常颠覆我的认知，因为GPT4虽然在事实正确性上和多模态上有改进，但GPT3.5才是真正实现逻辑能力涌现的，如果和GPT3.5已经差距不大了，那相对乐观呀！

直到我拿到了测试资格测了一下，发现国产LLM和ChatGPT根本不是一个物种……

于是我又回去翻看了一下其他人测评的时候测试的方式，我发现大家喜欢从各个角度问一个具体问题，然后看哪个LLM的回答看起来更靠谱。比如测试数学能力就出个鸡兔同笼，测试编程能力就考个leetcode题，测创造能力就安排写个文案。

怎么说呢，这种测试还真挺应试教育考试的既视感的。想提高这种能力，多搞点这些领域的数据，填鸭式教育让LLM多压缩点领域知识即可。从这个角度比较ChatGPT确实也不会比国产LLM强太多……

因为ChatGPT的In Context Learning逻辑能力是体现在超强的上下文和理解能力上的。这种一句话考试，体现的更多是背题能力，因为推导过程太有限了，基本只有COT激发出来的那一点点推导，这种推导是远远不够准确解决问题的。

我在前几天写的知乎贴子里（[mackler：自举：ChatGPT的AGI之路](https://zhuanlan.zhihu.com/p/623585915)）表达过一个观点，LLM吐出回答不能完全和人对话对应。

> 人类除了用语言说，还有用脑子想的过程，"想"这个过程也会有大量常识面和思维面的信息提取到kv  history中，"说"的可能只是最后的结论。而LLM的"想"和"说"都是建立在token序列上的，能直接吐出来的东西都是偏常识面的东西，某种意义上讲，LLM很像三体人。如果按照人类的习惯希望能跳过"想"的过程直接说，很多能力就会变得不容易实现，比如算术。人做算术，小数是通过口诀记忆，属于常识面的，大数则是通过思维面的算术方法结合小数的口诀来实现的。但如果期望跳过计算过程直接得到结果，准确性只能依赖背更多的口诀。

试想一下，如果把上面那些一句话测例用来考聪明的你，然后不允许你有任何“想”的过程去思考和组织语言，直接说出答案来，你大概率也说不出什么靠谱的回答，可能你也不一定能答过那些背过比你更多题库的人。

ChatGPT更正确的使用方法应当是AutoGPT或者OpenAI官方搞的插件系统那种用法。在用户“问”和GPT“答”之间，占用很多token去完成“想”以及与外部交互的迭代过程。这个过程中是可以充分利用GPT通过压缩得到的世界模型和In Context Learning的能力，提升最终“答”的质量。

也就是说，我们不能指望ChatGPT是个问啥都能给出好答案的oracle，人类提出问题，经过模型内部压缩出来的人类不可理解的“智慧”得到非常好的答案，这种期望是不太现实的。LLM也同样要模拟人“想”的过程，只不过有一个更丰富的世界知识，比我们所有人都知识丰富，未来也有可能逻辑能力比人类更强，比我们所有人都聪明，但仍然逃不掉人类通过“想”和实践得到一些可能的答案。

LLM模型的能力既包括深度学习“压缩”的世界知识，也包括LLM涌现出的全新的上下文逻辑能力。前者需要模型尺寸，后者需要Token序列长度，当然也需要模型能在这个长度Token序列上泛化上下文逻辑能力。而像AutoGPT和OpenAI官方的插件系统，都是建立在ChatGPT超强的上下文逻辑能力。

很可惜，这个能力国产LLM还没有，虽然Token序列长度还可以，但不丢失逻辑性的长度甚至不超过一段话，还是LLM涌现前的形态。坦率讲，复现LLM方面短期内我还是比较悲观，在各个大厂巨大的复现压力下，垂直场景快速做出“竞争力”是存在捷径的，通过更多垂直场景的数据即可，但这终归还是没“涌现”。哪怕做了很多头部场景，取得一个又一个进展，这些垂直场景的“深耕”未来迟早要被超强的上下文能力+插件+“想”的通用方案全部收割掉。
