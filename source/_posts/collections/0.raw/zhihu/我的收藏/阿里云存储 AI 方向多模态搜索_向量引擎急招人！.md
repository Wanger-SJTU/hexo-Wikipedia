【团队介绍】
我们是阿里云存储事业部旗下的表格存储（Tablestore）团队，致力于解决海量结构化数据的高性能存储与实时检索难题。
表格存储（Tablestore）是阿里云自研的面向海量结构化数据的基础存储服务，被广泛用于社交、物联网、元数据、大数据和 AI 等核心业务领域。从写下第一行代码起步，Tablestore 已全面支撑淘宝、支付宝、钉钉、菜鸟、夸克、通义千问等阿里巴巴集团核心产品，并逐步成为阿里云飞天操作系统的关键内核组件之一，实现全球化部署，服务数以万计的内外部客户，我们逐步获得了更多业务的信任，也逐步建立起了稳定、高竞争力和高性价比的口碑。
当前我们的 AI 检索产品已经成为阿里巴巴集团的基础设施，一是作为阿里云内云产品的元数据和检索底座，二是作为语义检索的基础设施为 SasS 类产品提供全文和向量检索能力，三是作为 Agent 、RAG 和 Mem 的存储底座为 Agent 各种框架提供存储和检索能力。
当前由于 AI 业务发展迅速，准备招聘一些经验丰富、技术扎实的研发，主要的工作内容是检索引擎、向量引擎的内核、分布式系统的设计研发和稳定性保障，以及 Agent、RAG 和 Mem 系统研发和效果优化等工作。

【职位描述】

- 负责阿里云分布式检索引擎、向量引擎和 AI Memory 的设计、开发、测试、稳定性保障和业务支持。
- 负责阿里云存储 AI 检索和 Agent 存储相关功能的产品化落地。
- 负责 AI 检索系统中的索引构建、检索、算分排序等模块的架构设计、开发、性能优化和稳定性保障工作。
- 负责向量检索引擎的设计、开发、优化和稳定性保障，打造具备竞争力的向量存储和检索系统。
- 负责大规模分布式系统的架构设计与演进，解决多租户隔离、弹性扩展、负载均衡、成本控制及架构升级等挑战。
【职位要求】

- 熟练掌握 Java 或 C++ 编程语言，具备丰富的 Code Review 经验以及内存管理、CPU、JVM 调优、锁竞争等系统级性能优化经验。
- 具备扎实的计算机科学功底和编程能力，具有良好的编程习惯。
- 具备独立模块或系统的需求分析、架构设计和编码能力，保证高并发后端系统的架构稳定性。
- 具备出色的问题分析与解决能力，能够独立负责复杂模块的设计与开发。
- 具备强烈的工作责任心、良好的学习能力、自驱力和沟通能力。
- 具备以下经验者优先：
- 深入阅读过 Elasticsearch、Lucene、Faiss 和 Milvus 等检索系统或向量领域开源系统。
- 有分布式系统、文档解析、Query 预处理、Ranker 排序模型等实际开发经验。
- 在 ACM/ICPC、NOI 等编程竞赛中获得奖项。
