Transformer是现代大模型的祖宗
分宗立派
- 宏观定位与分类：

- Transformer 是基于注意力机制的深度学习模型，抛弃了循环（RNN）和卷积（CNN）。
- 三大变体：

- Encoder-Decoder（标准架构）：如原始 Transformer，适用于序列到序列（Seq2Seq）任务（如翻译）。
- Encoder-only：如 BERT，适用于理解任务（分类、实体识别）。
- Decoder-only：如 GPT，适用于生成任务。

- 整体架构：
- 模型由 Encoder（编码器） 和 Decoder（解码器） 两大部分组成。
- 堆叠结构：Encoder 和 Decoder 各自由 多个相同的层堆叠而成，这种深度结构增强了表达能力。

- 数据流向：

- 输入阶段：输入序列 →→ Embedding（词嵌入） + Positional Encoding（位置编码）。
- 编码阶段：数据流经 Encoder 堆叠层，输出包含上下文信息的语义矩阵（Key 和 Value 供解码器使用）。
- 解码阶段：Decoder 接收目标序列的输入（Masked），结合 Encoder 的输出，逐个生成下一个 Token。
- 输出阶段：通过 Linear 层和 Softmax 层将向量转换为词表上的概率分布。

- 辅助/关键组件：

- Residual Connection（残差连接）：解决深层网络退化问题，公式为 x+Sublayer(x)x+Sublayer(x)。
- Layer Normalization（层归一化）：在每个子层后进行归一化，加速收敛并稳定训练。
- Masking（掩码）：特别是在 Decoder 中，防止模型“偷看”未来的词。

Transformer是做什么的？一个好的翻译过程不是逐字翻译，而是先理解原文的深层含义，再生成译文。

中式翻译：

我要给你点颜色看看。-  I give you color see see

真实语义：我要给你点教训  Transformer就是理解语义并翻译出贴合语义的译文。

Transformer编码器和解码器，主要分为三部分：
输入与位置编码
多头自注意力和前馈神经网络
辅助结构-稳定与决策（残差和归一化， linear和softmax）
组件一：输入与位置编码
- Embedding：输入文本中的每个词（token）被转换成一个固定维度的向量
- 顺序问题： 注意力机制本身对词语的位置不敏感，例如：对于注意力模块，猫吃鱼和鱼吃猫的计算结果非常相似，但是他们的含义完全不同。
- 位置编码：为每个词向量额外增添token在句子中的位置信息，位置信息也是与词向量相同维度的向量。

凡用注意力机制都会添加位置编码Transformer 这么厉害，为什么连单词的顺序都不知道？

痛点：Transformer 的“脸盲症”
首先要指出 Transformer 和 RNN 的根本区别：

- RNN（接力跑）：自带时序。读完“我”再读“爱”，读完“爱”再读“你”。在这个过程中，顺序是内嵌在时间步（Timestep）里的，不需要额外处理。
- Transformer（大合唱）：并行计算。它是一眼把“我爱你”三个字同时看进去的。问题出现了：
对于 Transformer 来说，如果不加位置信息：

"猫吃鱼" 
"鱼吃猫" 
这两句话在模型眼里是一模一样的！ 因为它们包含的词汇完全相同。结论：必须人为地给每个词“贴上标签”，告诉模型谁在第一位，谁在第二位。

方案选择：为什么是正弦余弦？

- 方案 A：用整数标记 (1, 2, 3...)

- 缺陷：句子越长，数字越大（比如第 1000 个词标记为 1000）。这也太大了，会破坏神经网络权重的平衡（梯度爆炸/消失）。

- 方案 B：归一化到 [0, 1] (0.1, 0.2 ... 1.0)

- 缺陷：步长不固定。5 个词的句子，间距是 0.2；100 个词的句子，间距是 0.01。模型很难学到一个统一的“距离感”。

组件二：多头注意力 、前馈神经网络

多头注意力（multi-head attention）：这是Transformer的核心，它的任务是计算句子中的每个词与其他词的关联度（注意力），从而理解上下文。

前馈神经网络（feed forward networ，FFN）：注意力模块捕捉了上下文关系后，FFN对每个词的向量进行独立的，更深层的非线性处理增加模型的表达能力。

词和词的关联关系，更好理解上下文。

我叫小苹果
我吃苹果
我用苹果手机
单头注意力

注意力公式
- Q（Query）、K（Key）、V（Value）都是从输入向量线性映射得到。
 
-  通过这个公式，每个 token 都可以“关注”序列中的其他 token，并得到加权表示。
 
-  但如果只用单个注意力头，模型只能学习一种“关系模式”，比如只能学局部依赖或者全局依赖，但很难同时捕捉多种关系。多头注意力的核心思想

多头注意力就是 并行使用多个注意力机制（头），每个头都有自己的一组 Q、K、V 权重：

- 每个头独立学习注意力模式
-  一个头可能关注句子中的局部结构（邻近词）
-  另一个头可能关注全局关系（远距离依赖）
- 让模型同时捕捉不同的语义信息
-  举例：句子 “The cat sat on the mat.”
-  一个头可能关注 “cat ↔ sat”
-  另一个头可能关注 “sat ↔ mat”
-  还有一个头可能关注定冠词 “The ↔ cat”
 
优点

- 捕捉多种语义关系：不同头可以学习不同的关注模式。
- 增强表达能力：比单头注意力更灵活、更强大。
- 易于并行计算：各个头可以同时计算，不影响训练速度。 小矩阵示意

2. 为什么要加残差
核心目的：解决深层网络的训练困难问题

（1）缓解梯度消失 / 梯度爆炸

-  残差连接提供了一条“梯度高速通道”
-  即使子层学不到东西，网络至少可以学习到 恒等映射
（2）降低子层学习难度

-  子层不再需要学习完整映射
-  只需学习一个 增量修正（residual）
（3）信息不丢失

-  Attention / FFN 可能“破坏”原始 token 表征
-  残差保证原始语义始终存在

FFN

- FFN（前馈神经网络）是“消化/思考”：
- Attention 把上下文信息收集来之后，FFN 负责在一个独立的封闭空间里，对这些收集来的信息进行提炼、非线性变换和整合。
- 本质：是每个词是独立进入 FFN 进行计算的，互不干扰。“Attention 就像是你在开会时听取大家的意见（收集信息），而 FFN 就像是你开完会回到工位上，
自己一个人静下来把刚才听到的东西整理、消化，变成自己的理解（加工信息）。”
从微观结构上看，FFN 做了一个非常特殊的**“扩充-筛选-压缩”**动作。

先升维再降维
- 公式：
             FFN(x)=ReLU(xW1+b1)W2+b2

- 维度变化：
- 输入：512 维（dmodel）。
- 第一层 Linear（扩充）：变成了 2048 维（4×dmodel）。
- 激活函数（ReLU）：在这里进行非线性筛选（把负数截断为0，保留重要特征）。
- 第二层 Linear（压缩）：变回 512 维。“FFN 中间有一个变胖的过程（从 512 变到 2048）。
这就像我们理解一个复杂的概念时，需要先把书展开（升维），把细节全部摊开来看清楚，通过 ReLU 划重点，最后再把书合上（降维），只记住最精华的 512 维核心要义传递给下一层。”Attention 负责关系（Relations）：学习词与词之间的语法依赖、指代关系。
FFN 负责知识（Knowledge）：FFN 的权重矩阵里实际上存储了大量的具体事实知识。
例子：当问“法国的首都是哪里？”
Attention 负责把“法国”和“首都”这两个词关联起来。
FFN 的权重里“存储”了“巴黎”这个概念，当它接收到“法国+首都”的向量输入时，FFN 会被激活并输出包含“巴黎”语义的向量。
输出层

输出层
- 位置：模型的最末端。
- 功能：语义到符号的映射。
- 逻辑：“把抽象的‘高维语义向量’（只有计算机懂）通过一个巨大的 Linear 矩阵，映射到‘人类词表’（人类懂）。”Linear 层的“几何直觉”

1. 核心公式

- x  ：输入向量。
- W ：权重矩阵（Weight，决定了旋转和缩放）。
- b  ：偏置向量（Bias，决定了平移）。
2. 几何动作分解
Linear 层对数据空间做了三件事：

- 旋转（Rotation）：
- 就像扭转魔方。Linear 层把数据转到一个新的角度，使得特征更容易被区分。
- 例子：原本“苹果”和“梨”混在一起，转个角度看，就能画条线分开了。
- 缩放（Scaling）：
- 拉伸或压缩某些维度。
- 例子：模型发现“颜色”这个特征对于分辨水果很重要，就通过权重矩阵把“颜色”维度的数值放大；发现“形状”不重要，就把它缩小。
- 平移（Translation）—— 偏置项 Bias 的作用：
- 把数据整体挪个位置。
- “为什么要加 Bias (b)？”
- 解释：如果没有 Bias，所有的线性变换都必须经过原点 (0,0)。这就像这就限制了切蛋糕的刀必须经过蛋糕中心。加上 Bias，刀就可以随便切了。

从 Decoder 的最后一层输出一个抽象的向量，到最终变成我们能看懂的中文（比如“苹果”），中间经历了 两个关键步骤：Linear 投影 和 Softmax 归一化。

我们可以把这个过程比喻为 “全员打分” 到 “胜率计算” 的过程。

第一步：Linear 层 —— 全员打分（得到 Logits）
Decoder 的最后一层输出了一个向量（假设是 512 维）。这个向量是机器脑海中的“意念”，它包含了下一个词的语义特征（比如：名词、红色、水果、圆形）。

但是，机器需要从词表（假设有 30,000 个词）里挑出一个词。

1. 动作：投影（Projection）
Linear 层是一个巨大的矩阵，形状是 

512×30000 

- 输入：那个 512 维的“意念向量”。
- 操作：矩阵乘法。
- 含义：拿“意念向量”去和词表中 30,000 个词的特征向量 一一比对。
2. 结果：Logits（未归一化的得分）
Linear 层会输出一个长度为 30,000 的列表。列表里的每一个数字，代表对应的词和当前“意念”的 匹配分数。

- 分数特点：

- 可以是正数，也可以是负数（负数代表完全不搭边）。
- 数值大小没有上限（比如 15.6, -3.2, 0.1）。
- 这组数在深度学习中被称为 Logits。举例：
假设词表只有 4 个词：[香蕉, 汽车, 苹果, 跑]。
Decoder 想要表达“红色的水果”。Linear 层打分结果（Logits）可能如下：
- 香蕉：2.0 （有点像水果，但颜色不对）
- 汽车：-5.0 （完全不对）
- 苹果：10.0 （非常匹配！）
- 跑：-3.0 （词性都不对）
第二步：Softmax 层 —— 胜率计算（得到 Probability）
Logits 虽然能看出谁分高，但它不是概率（加起来不等于 1，还有负数）。我们需要用 Softmax 函数 对这些分数进行“整形”。

公式：

这个公式做了两件事：

1. 指数放大（Exponentiation）
把所有分数变成 e 的x次方

- 作用 A：消灭负数。无论 Logit 是 -5 还是 -100，变成 e−5后都是正数（虽然很小）。
- 作用 B：拉大差距（Rich get richer）。
- Logit 2.0 和 10.0 看起来只差 8 分。
- 但在指数世界里：
e2≈7.4e2≈7.4
，而 e10≈22026e10≈22026。
- 结果：原本得分高的词，经过 Softmax 后，优势会被瞬间放大，变成绝对的主导。
2. 归一化（Normalization）
把每个词的指数结果，除以所有词指数结果的总和。

- 作用：保证所有数值加起来等于 1（即 100%）。经过 Softmax 处理后，Logits 变成了概率：
- 香蕉：0.003 (0.3%)
- 汽车：0.000 (0%)
- 苹果：0.996 (99.6%)
- 跑：0.001 (0.1%)结果：模型可以自信地说：“下一个词有 99.6% 的概率是‘苹果’。”

第三步：输出决策 —— 怎么选词？
得到了这个概率分布表后，翻译任务通常有两种选择策略：

- 贪婪搜索 ：
- 简单粗暴，直接选概率最大的那个词。
- 在这个例子里，直接输出“苹果”。
- 集束搜索  ——（翻译任务常用）：
- 为了防止“一步错步步错”，模型会保留概率最高的 前 K 个 候选词（比如前 5 个）。
- 然后在生成下一个词时，继续推演这 5 条路径，最后看哪条路径的总概率最高。总结

在GPT中调整temperature为什么会影响输出概率？

Temperature（温度） 是一个作用在 Softmax 之前 的缩放系数。它并不改变各个词得分（Logits）的排名（谁是第一），但它会改变各个词之间概率的**“贫富差距”**。

显然“苹果”得分最高。

- 调小 (Cold) = 分布变尖 = 保守/精确/单一在 Decoder 中，这种机制被称为 Look-Ahead Mask（前瞻掩码） 或 Subsequent Mask。它的核心目的只有一个：维持因果律，防止作弊。

1. 为什么要遮？（防止作弊的悖论）

训练时的特殊情况
在 Transformer 进行训练时，我们使用了一种叫 Teacher Forcing 的策略。
这意味着，我们不是一个字一个字生成的，而是一次性把整个正确答案（如 "Input: I love AI"）全部喂给了 Decoder。

问题来了
Self-Attention 的本能是“眼观六路”。

- 当 Decoder 在处理第一个词 "I" 的时候，它想知道“我是谁？”。
- 如果没有 Mask，Self-Attention 机制会直接看到整个句子的所有词（包括后面的 "love" 和 "AI"）。
- 后果：模型会发现——“哈！原来 'I' 后面就是 'love' 啊！”。它就不会去学习语法和语义推理，而是直接学会了**“抄袭下一个词”**。这就好比考试时，老师把整张卷子的答案都写在了题目旁边。学生（模型）根本不需要思考，直接把答案抄下来就能得满分（Loss 极低）。
但一到实战（推理/测试）阶段，没有答案可抄，模型就废了。

解决方案
必须强行规定：当你在看第 t 个词的时候，你只能看到 1到t那个词，绝对不能看到

t+1
及以后的词。

2. 怎么遮？（基于矩阵的魔法）

假设句子是 "I love AI" (3个词)。Self-Attention 会计算一个

的矩阵，代表“谁在关注谁”。

我们要强行把“右上角”（未来区域）盖住。在数学上，我们加一个下三角矩阵，把右上角设为  

-∞（负无穷大）。

第三步：Softmax 的妙用
为什么要设为负无穷，而不是 0？
回顾 Softmax 公式： e的x次方。

这就是对未来视而不见。
补充：Padding Mask 与 Look-Ahead Mask 的区别
要区分清楚两种 Mask，因为它们通常是叠加使用的：

- Padding Mask（Encoder 和 Decoder 都有）：
- 作用：句子长短不一，不够长的补了 0（Padding）。为了不让 Attention 注意到这些无意义的 0，我们要把它 Mask 掉。
- 比喻：不要盯着空白纸发呆。
- Look-Ahead Mask（只有 Decoder 有）：
- 作用：就是刚才讲的，遮挡未来。
- 比喻：不要偷看标准答案。在 Decoder 的代码中，通常有一行 mask = padding_mask   look_ahead_mask，意思就是：既不能看未来的词，也不能看凑数的 Padding。
