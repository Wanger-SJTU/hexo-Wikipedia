<strong>Ford-Fulkerson</strong>方法依赖于三种重要思想，<strong>残留网络、增广路径</strong>和<strong>割</strong>。<strong>Ford-Fulkerson</strong>方法是一种迭代的方法。开始时对所有的 u,v∈V 有 f(u,v)=0 ，即初始状态时流的值为0。在每次迭代中，可通过寻找一条"<strong>增广路径</strong>"来增加<strong>流值</strong>。<strong>增广路径可以看成是从源点s到汇点t之间的一条路径，沿该路径可以压入更多的流，从而增加流的值</strong>。反复进行这一过程，直至增广路径都被找出来，<strong>根据最大流最小割定理，当不包含增广路径时，</strong> f <strong>是</strong> G <strong>中的一个最大流。</strong>

<strong>上述过程伪代码如下:</strong>

Set Fmax = 0
Repeat until there is no path from s to t:

```text
     // 通过AugmentingPath(增广路径算法)寻找一条路径
     Run AugmentingPath from s to find a flow path to t
     Let cp be the minimum capacity value on the path
     Add cp to Fmax
     For each edge u -> v on the path:
          // 对于反向的边，根据反对称性求
          Decrease c(u,v) by cp
          // 对于在增广路径上的正向的边，加上增加的流
          Increase c(v,u) by cp
```


<strong>可以证明当无法寻找到路径时 F_{max} 就是最大流。</strong>

### 4.Push-Relabel算法(最大流)

<strong>Ford-Fulkerson方法</strong>还比较好理解，即每一次尝试都需要在<strong>剩余图</strong>里找到一条<strong>增强路径，</strong>让整个图的流量最大化。<strong>Push-Relabel</strong>算法与前面所讲的<strong>Ford-Fulkerson算法</strong>是另一种思路。

如果给你一个网络流，让你手算它的最大流，你会怎么算? 一般人都会尝试着从源点出发，让每条边的流量尽可能的大，然后一点点往汇点推，直到遇到一条比较窄的弧，原先的流量过不去了，这时再减少原来的量。其实这也是<strong>Push-Relabel算法</strong>的基本思路。

Push-Relabel算法，先在源节点处加入充足的流(<strong>与源节点相连的所有边的容量之和</strong>)，然后按一定规则进行流渗透，一个边一个边的向汇点渗透，直到没法再渗透(<strong>类似于Ford-Fulkerson算法中找不到增广路径</strong>)。顾名思义，Push-Relabel算法包含两个核心的操作:

<strong>1) Push:</strong>Push操作表示从所有节点找出一个存水量大于0(  0">e(u) > 0 )的节点 u ，将它所存的水尽可能推向与它相邻的节点 v 。要实现该push的操作必须满足下面条件:该点存水量 0">e(u)>0 <strong>且</strong>节点 u 的高度大于节点 v 的高度。本次推送的流值 f=min\{e(u),capacity(u,v)\} capacity(u,v) 为边 edge(u,v) 的当前容量。

<strong>2) Relabel:</strong>Relabel表示某一节点的存水量大于0( 0">e(u) > 0)，但水流不出去时，我们对该节点高度增加1，从而使得该节点的存水量流入比它低的节点。一开始的时候我们设置源节点( s )高度为 N ( N 为 G 的结点数)，所有其他节点高度为0，并且汇节点( t )的高度固定为0。除去 s 和 t 外，其他节点在算法执行过程中高度h会不断改变。

    return flag;
}

### 6.最小费用路算法(最小费用最大流)

前面所讲的最小费用流算法(<strong>Bellman-Ford、Dijkstra、SPFA等</strong>)中实际求得的是<strong>单位流量</strong>流经网络的最小费用。实际应用中单位流量是满足不了我们的需求的，因此提出了<strong>最小费用最大流问题</strong>，即最大流情况下的最小费用。

定义:对一费用容量网络，具有相同流量 f 的可行流中，总费用最小的可行流称为该费用容量网络关于流量 f 的最小费用流，简称流量为 f 的最小费用流。

最小费用路算法的思想是:<strong>先找最小费用路，在该路径上面增流，增加到最大流</strong>。利用邻接表建立双向边，正向边的花费为 cost ，反向边的花费为 -cost 。在找最小费用路的时候，从源点出发，沿着可行 ( E[i].flow">E[i].cap>E[i].flow )广度搜索每个邻接点， 如果当前的边可以继续松弛，那么就更新，就是SPFA算法，并且记录一下前驱。

当找到最小费用路以后，那么就从汇点向源点找一条，最小的<strong>可增流量</strong>,沿着增广路正向增流，反向减流，最后花费的费用为：mincost=dis[V]∗d 。累加这个过程求出来的就是最小费用，最大流就是每次累加的可增流量。

    // 计算从s到t的"单位"最小费用路
    while(spfa(s,t,n))
    {

        d=inf;

        for(int i=pre[t]; i!=-1; i=pre[E[i^1].v]) 
        {
            E[i].flow+=d;
            E[i^1].flow-=d;
        }

        // 更新费用(dis[t]为该路径上单位流量费用之和),单价[dis[t]]*流量[d]
        mincost+=dis[t]*d;
    }
    return mincost;

### 7.对偶算法(最小费用最大流)

<strong>所谓对偶法是实现同一目标的两种相反路径，对于最小费用最大流问题:</strong>

1).始终保持网络中可行流是最小费用流，然后不断调整，使流量逐步增大，最终成为最小费用的最大流。

2).始终保持可行流是最大流，通过不断调整使得费用逐步减小，最终成为最大流量的最小费用流。

可以证明两种路径是殊途同归的。依据第一条路径，算法原理为:若 X 是流量为 f(X) 的最小费用流， \mu 是关于 X 的所有增广链中费用最小的增广链，那么沿着 \mu 去调整 X 得到新的可行流 \tilde{x} ，就是流量为 f(\tilde{x}) 的最小费用流。<strong>因此，只要找到最小费用增广链，在该链上调整流量，得到增加流量后的最小费用流。循环往复直到求出最小费用最大流。</strong>

算法的关键是<strong>构造增广费用网络图，</strong>在此基础上借助最短路算法寻找最小费用增广链。增广费用网络图的构造方法是将网络中的每一条弧 (v_{i},v_{j}) 都变成一对方向相反的弧，以形成四通八达的"路"，权数定义如下:

<strong>Step1:</strong>用Frod-Fukerson算法求出容量网络的最大流量 f_{max} 

<strong>Step2:</strong>取初始可行流为零流，其必为流量为0的最小费用流。

<strong>Step3:在</strong>第 k-1 次迭代，得最小费用流 X^{k-1} , 对当前可行流构造增广费用网络图 W(X^{k-1}) , 用最短路算法求出从发点到收点的最短路。若不存在最短路，则 X^{k-1} 即为最小费用最大流，停止迭代，否则转下一步。

<strong>Step4:</strong>将最短路还原成原网络图中的最小费用增广链 \mu ，在 \mu  上对可行流 X^{k-1} 进行调整，得到新的可行流图，若其流量等于 f_{max} ,迭代结束。否则转入第一步，进入下一次的迭代过程。

### 11.有上下界的网络流算法

在一个有上下界的流网络 G 中，不设源和汇，但要求任意一个点 i 都满足流量平衡条件:

$\sum_{(u,i) \in E}^{}{f_{u,i}} = \sum_{(i,v) \in E}^{}{f_{i,v}} , 且每条边 (u,v) 都满足容量限制 B(u,v) \leq f(u,v) \leq C(u,v) 的条件下，寻找一个可行流 f , 或指出这样的可行流不存在。这样的问题称为无源汇的可行流。$

首先很显然的，我们可以想到，<strong>如果把所有边的下界都一定要取到，所以把它们都从上界中减去，然后再在剩下来的网络中求一个可行流</strong>。那么它是原来网络中的可行流吗？这样的转化是不对的，因为它并<strong>不满足流量守恒这一个条件</strong>。

为了弥补这一不足，我们可以给这个转化过的网络<strong>附加上一个源和汇</strong>。

如果设：

$$M(i) = \sum_{(u,i) \in E}^{}{B(u,i)} - \sum_{(i,v) \in E}^{}{B(i,v)} $$

即 M(i) 为流入结点 i 的下界总和减去流出 i 的下界总和。如果 M(i) 是正数，设一附加源

S_{0} ，则可以令 C’(S_{0}, i) = M(i) ，否则设一附加汇*T*0，令 C’(i, T_{0}) = -M(i)。 

如果所有从源点流出的弧和流入汇点的弧都满载，那么该网络存在一个<strong>可行流</strong>。原图中每一条边的流量应为<strong>新图中对应的边的流量</strong>+<strong>这条边的流量下界。</strong>
