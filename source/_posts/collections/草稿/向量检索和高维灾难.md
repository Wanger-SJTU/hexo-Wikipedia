LLM之后，向量数据库受到的关注度也越来越高，不仅专用的数据如chromadb、pgvector等，在传统数据库里面也开始集成向量检索的功能。
虽然向量数据库是最近火的，但实际的功能确实在检索领域开始发展的，在LLM的场景下情况有了细微差别，向量维度大幅增长。比如图片搜索大概256左右的向量维度就可以，如果单纯的文本相似度检索，其实几百的维度也可以了，毕竟这里只看召回就可以，对于精确度的要求没那么高。但在RAG的场景里面，精度的重要性上升了，毕竟大k场景召回多了，后续处理的成本就高了。

最近也恰好回忆起之前看到这个问题的讨论，放在一起记录一下：

## SAM 蒸馏 loss 不收敛
> 发现学生网络在Imagenet上损失根本降不下来，精度也上不去，搞得我一度怀疑人生，强迫症发作想把框架的bug找出来，结果一陷就是一两周，后来还是因为发现论文实验的Baseline出了问题才终于停下来。

参考1中现象，作者得到一个猜测——<strong>所有在低维空间中有用的经验，在高维空间中都有可能失效。</strong> 
当然这里作者用的是L2的距离，对于其他距离会怎么样，需要继续讨论。

## 空间范数扩展到高维的分析
*这里出自文章2*

常见的$L_p$ 范数定义 $\lvert \boldsymbol{x} \rvert_p=(\sum_{i=0}^{n}x_i^p)^{\frac{1}{}p}$， 到高维空间则有
$$
If \lim_{d\rightarrow\infty} var(\frac{\lvert X_d\rvert_k}{E[\lvert X_d \rvert_k]}) = 0 \quad then, \frac{Dmax_d^k-Dmin_d^k}{Dmin_d^k} \rightarrow_p 0
$$
到给定<strong>点1</strong>的<strong>最大和最小距离之间的差</strong>不会像<strong>在高维空间中到任何点的最近距离一样快</strong>。这使得K近邻算法变得毫无意义且不稳定，因为最近和最远的邻居之间的区分度很低。
refto:[link](https://stats.stackexchange.com/questions/99171/why-is-euclidean-distance-not-a-good-metric-in-high-dimensions)
对于N个样本，这N个样本中距离最远的两个样本之间的距离Dmax和距离最近的两个样本之间的距离Dmin，在维度越高的情况下，越趋近于相同。
也就是说，维度趋于无穷大的情况下，这N个样本之间，所有点和其它的点基本上彼此均匀地相距，此时点之间的距离是没有意义的因为所有点到其它点的距离都趋于相同。

用几何来解释一下， $n$ 维欧式空间单位超球体的[体积公式](https://www.zhihu.com/search?q=%E4%BD%93%E7%A7%AF%E5%85%AC%E5%BC%8F&search_source=Entity&hybrid_search_source=Entity&hybrid_search_extra=%7B%22sourceType%22%3A%22answer%22%2C%22sourceId%22%3A3301505885%7D)为 ，为伽马函数$V_n(R) = \frac{\pi^{n/2}}{\Gamma\bigl(\tfrac n2 + 1\bigr)}R^n$，$\Gamma$为伽马函数 ，对任意 $\forall \epsilon>0$ , $\lim_{n \rightarrow \infty}{\frac{V_n(r+\epsilon)}{V_n(r)}} = \frac{(r+\epsilon)^n}{r^n}= \infty$，换句话说就是高维超球体绝大部分体积都在球表面一层薄壳中。这个结论对超立方体也适用。

基于这个性质，我们在单位超球体内均匀采样时，大多数点将会位于球体表面的很薄的薄壳里，半径为0.999的球体内点的数量随着维数变大趋近于零，也就意味着距离度量无法刻画样本数量。

另一个例子是假设有一组 n 维空间的数据点，每一维度的数据在固定范围内，其中绝大部分维度是纯粹的噪声且这些噪声是独立同分布的，随着 nn 的增大，数据点之间的距离分布将集中在一个值周围，这就意味着我们无法根据距离来做相似性判断。但如果数据大部分维度并非随机噪声，与类别有一定相关性，维度变大并不会造成上述问题，换句话说特征选择很重要。

仿真一下：

```python
import numpy as np
import matplotlib.pyplot as plt
number_of_samples = 10000
dimension = 20

# 有两类数据，
# A类数据，第一个维度为0，其他维度为均匀分布的在[-0.1,0.1]内随机噪声
# B类数据，第一个维度为1，其他维度为均匀分布的在[-0.1,0.1]内随机噪声

#计算A类数据内部点的距离
dist_same = []
for _ in range(number_of_samples):
    p1 = np.random.random_sample((dimension,1)) * 0.2 - 0.1
    p1[0] = 0
    p2 = np.random.random_sample((dimension,1)) * 0.2 - 0.1
    p2[0] = 0
    dist_same.append(np.linalg.norm(p1-p2))
#计算A类和B类数据之间点的距离
dist_diff = []
for _ in range(number_of_samples):
    p1 = np.random.random_sample((dimension,1)) * 0.2 - 0.1
    p1[0] = 0
    p2 = np.random.random_sample((dimension,1)) * 0.2 - 0.1
    p2[0] = 1
    dist_diff.append(np.linalg.norm(p1-p2))
plt.hist([dist_same,dist_diff], bins=100)
plt.legend(["dist_same","dist_diff"])
plt.title(f"Dimension: {dimension}")
plt.show()
```
