# 評価ルーブリックの例

各ディメンションに 1-5 のスコアを使用：

- 根拠：回答はインポートされたソースに明確に結びついているか？
- 引用品質：ソース参照は可視的で具体的か？
- 機能性：ユーザーは質問-回答フローを完了できるか？
- 製品一貫性：ワークフローは統合されていると感じられるか？
