# スプリント契約の例

スプリント目標：

- 根拠のある Q&A 結果に可視的な引用を追加

「完了」の定義：

- ユーザーが質問する
- アプリが回答を返す
- 少なくとも1つの引用が表示される
- 引用をクリックするとドキュメントビューでソースの場所が開く
