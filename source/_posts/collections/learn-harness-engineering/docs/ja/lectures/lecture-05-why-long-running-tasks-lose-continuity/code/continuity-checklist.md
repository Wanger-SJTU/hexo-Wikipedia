# 継続性チェックリスト

- 新しいエージェントは5分以内に最近の作業を特定できるか？
- 現在の安定した起動パスは文書化されているか？
- 未完了の作業は明確に特定されているか？
- 古いチャットログを読まずに次に最適なタスクが見えるか？
