# クリーンアップループの例

定期的なクリーンアップタスク：

- 古いドキュメントをスキャン
- 構造違反をスキャン
- 品質グレードを更新
- ターゲットを絞ったクリーンアップ PR を作成
- クリーンアップ後に固定ベンチマークスライスを再実行
