# データベーススキーマ

このフォルダーは、エージェントがコードからリバースエンジニアリングすることなく
確認できる、生成済みまたは派生した成果物のために使用します。

## ソース

- 生成元: `[command or source path]`
- 最終更新日: `YYYY-MM-DD`

## 注意事項

- 生成されたセクションは手動で編集しないでください。
- 基になるスキーマが変更された場合は、このファイルを再生成してください。
