# プロダクト仕様 インデックス

このフォルダーは、現在のユーザー向け動作仕様のために使用します。

## アクティブな仕様

- `new-user-onboarding.md`

## ルール

- 仕様はユーザーに見える動作と受け入れ基準を記述する。

- 新しいエージェントがプロダクトのスコープを素早く発見できるよう、このインデックスを最新に保つ。
