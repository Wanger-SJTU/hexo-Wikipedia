# Ejemplo de Bucle de Limpieza

Tareas de limpieza recurrentes:

- escanear docs obsoletos
- escanear violaciones estructurales
- actualizar notas de calidad
- abrir PRs de limpieza dirigidos
- reejecutar un slice de benchmark fijo después de la limpieza
