# Ejemplo de Contrato de Sprint

Objetivo del sprint:

- Añadir citaciones visibles a los resultados de Q&A fundamentado

"Hecho" significa:

- El usuario hace una pregunta
- La app devuelve una respuesta
- Se muestra al menos una citación
- Hacer clic en una citación abre la ubicación fuente en la vista de documento
