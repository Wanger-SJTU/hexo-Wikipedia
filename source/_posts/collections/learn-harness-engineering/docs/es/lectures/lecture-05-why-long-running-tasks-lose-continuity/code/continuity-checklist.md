# Lista de Verificación de Continuidad

- ¿Puede un agente nuevo identificar el trabajo reciente en menos de cinco minutos?
- ¿Está documentada la ruta de inicio estable actual?
- ¿Está el trabajo sin terminar claramente identificado?
- ¿Es visible la siguiente mejor tarea sin leer registros de chat antiguos?
