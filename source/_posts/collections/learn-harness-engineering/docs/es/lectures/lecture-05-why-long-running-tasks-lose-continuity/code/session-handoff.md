# Ejemplo de Entrega de Sesión

## Completado

- Añadido soporte de importación de Markdown
- Añadida una lista básica de documentos en el renderer

## Roto o No Verificado

- La importación funciona para `.md` pero falla para archivos `.txt` grandes
- La app arranca, pero la vista de detalles no está conectada

## Siguiente Mejor Paso

- Corregir la ruta de importación de `.txt`
- Verificar la importación end-to-end
- Luego añadir el panel de detalles del documento
