# Índice de Especificaciones de Producto

Usa esta carpeta para las especificaciones actuales del comportamiento visible al usuario.

## Especificaciones Activas

- `new-user-onboarding.md`

## Reglas

- Las especificaciones deben describir el comportamiento visible al usuario y los criterios de aceptación.
- Si la implementación diverge de la especificación, actualiza una de ellas en la misma sesión.
- Mantén este índice actualizado para que un agente nuevo pueda descubrir el alcance del producto rápidamente.
