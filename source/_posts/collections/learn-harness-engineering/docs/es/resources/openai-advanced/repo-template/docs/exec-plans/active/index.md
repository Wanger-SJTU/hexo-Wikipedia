# Planes activos

Mantén un archivo markdown por cada plan de ejecución activo en esta carpeta.

Patrón de nombre de archivo sugerido:

- `YYYY-MM-DD-short-topic.md`

Cada plan activo debería estar lo suficientemente actualizado para que una sesión nueva
de agente pueda reanudar el trabajo solo desde el repositorio.
