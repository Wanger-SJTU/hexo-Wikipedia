# Aktive Pläne

Bewahren Sie eine Markdown-Datei pro aktivem Ausführungsplan in diesem Ordner auf.

Vorgeschlagenes Dateinamenmuster:

- `YYYY-MM-DD-kurzes-thema.md`

Jeder aktive Plan sollte aktuell genug sein, damit eine neue Agenten-Sitzung die
Arbeit allein aus dem Repository fortsetzen kann.
