# Abgeschlossene Pläne

Verschieben Sie fertige Pläne hierher, anstatt sie zu löschen. Abgeschlossene Pläne
sind Teil der Repository-Gedächtnisoberfläche und helfen späteren Agenten-Sitzungen
zu verstehen, warum der Code so aussieht, wie er aussieht.
