# Aufräum-Schleife Beispiel

Wiederkehrende Aufräumaufgaben:

- Nach veralteten Dokumenten scannen
- Nach Strukturverletzungen scannen
- Qualitätsnoten aktualisieren
- Gezielte Aufräum-PRs öffnen
- Ein festes Benchmark-Slice nach dem Aufräumen erneut ausführen
