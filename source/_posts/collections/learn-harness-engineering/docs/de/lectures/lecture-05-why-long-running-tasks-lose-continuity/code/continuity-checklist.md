# Kontinuitäts-Checkliste

- Kann ein neuer Agent aktuelle Arbeit in unter fünf Minuten identifizieren?
- Ist der aktuelle stabile Startpfad dokumentiert?
- Ist unvollständige Arbeit klar gekennzeichnet?
- Ist die nächste beste Aufgabe ohne Lesen alter Chat-Protokolle sichtbar?
