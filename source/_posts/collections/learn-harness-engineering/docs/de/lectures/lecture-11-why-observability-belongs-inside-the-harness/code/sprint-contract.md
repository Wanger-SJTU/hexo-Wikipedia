# Sprint-Vertrag Beispiel

Sprint-Ziel:

- Sichtbare Zitate zu fundierten Q&A-Ergebnissen hinzufügen

"Fertig" bedeutet:

- Benutzer stellt eine Frage
- App gibt eine Antwort zurück
- Mindestens ein Zitat wird angezeigt
- Klicken auf ein Zitat öffnet die Quellposition in der Dokumentansicht
