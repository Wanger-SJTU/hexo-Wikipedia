# Clean-State-Checkliste

- App startet ohne manuelle Reparatur
- Aktueller Fortschritt ist dokumentiert
- Kein halbfertiger Import- oder Indexierungsschritt bleibt undokumentiert
- Der nächste Agent kann den Standard-Start- und Verifikationspfad sofort ausführen
