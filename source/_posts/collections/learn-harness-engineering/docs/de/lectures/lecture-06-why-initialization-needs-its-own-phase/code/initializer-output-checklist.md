# Initialisierer-Ausgabe Checkliste

- Gibt es einen kanonischen Startbefehl?
- Gibt es einen kanonischen Verifikationsbefehl?
- Gibt es ein erstes Fortschritts-Artefakt?
- Gibt es einen stabilen ersten Commit?
- Gibt es eine sichtbare Feature-Oberfläche für spätere Sessions?
