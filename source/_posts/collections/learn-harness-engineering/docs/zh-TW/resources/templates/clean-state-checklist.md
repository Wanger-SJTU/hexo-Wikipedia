# 乾淨狀態檢查清單

- [ ] 標準啟動路徑仍可使用。
- [ ] 標準驗證路徑仍可執行。
- [ ] 目前進度已記錄在進度日誌中。
- [ ] 功能狀態真實反映哪些項目已通過，哪些仍未驗證。
- [ ] 沒有半完成的步驟處於未記錄狀態。
- [ ] 下一個工作階段不需要人工修復就能繼續。
