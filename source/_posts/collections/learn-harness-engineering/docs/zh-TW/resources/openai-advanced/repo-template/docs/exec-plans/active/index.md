# 目前執行計畫

這個資料夾中的每份 markdown 檔案，都代表一份仍在進行中的執行計畫。

建議檔名格式：

- `YYYY-MM-DD-short-topic.md`

每份目前執行計畫都應維持最新，讓新的代理工作階段只靠儲存庫也能接續工作。
