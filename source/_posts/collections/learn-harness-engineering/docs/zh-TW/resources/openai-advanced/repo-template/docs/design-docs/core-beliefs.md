# 核心信念

- 儲存庫是代理的唯一事實來源。
- `AGENTS.md` 是路由器，不是百科全書。
- 驗證證據比自信更重要。
- 一次完成一個有邊界的任務，勝過同時留下許多半成品。
- 反覆出現的人類回饋，應該升級成可重複使用的執行環境規則。
- 清理與簡化屬於交付的一部分，不應留到事後處理。
- 如果代理無法在儲存庫中發現某個事實，就把它視為執行上無法取得。
