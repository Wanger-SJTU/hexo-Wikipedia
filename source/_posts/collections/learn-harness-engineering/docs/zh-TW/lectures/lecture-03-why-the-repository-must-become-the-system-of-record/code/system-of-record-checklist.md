# 系統記錄檢查清單

一個全新的 Agent 能否僅從 repo 中發現以下資訊？

- 正在建構什麼產品？
- 應用程式應該為使用者做什麼？
- 程式碼庫如何組織？
- 應用程式如何啟動？
- 如何檢查健康狀態？
- 目前正在進行什麼工作？
- 哪些品質標準很重要？
