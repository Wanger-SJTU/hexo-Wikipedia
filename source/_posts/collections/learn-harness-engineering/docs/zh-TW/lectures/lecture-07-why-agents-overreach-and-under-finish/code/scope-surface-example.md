# 範圍表面範例

任務：

- 為 Electron 知識庫應用程式新增索引功能

不良的範圍形狀：

- 「實作索引功能」

較好的範圍形狀：

- 解析已匯入的文件
- 將文件分割為區塊
- 持久化區塊詮釋資料
- 在 UI 中顯示索引狀態
- 新增重新索引操作
