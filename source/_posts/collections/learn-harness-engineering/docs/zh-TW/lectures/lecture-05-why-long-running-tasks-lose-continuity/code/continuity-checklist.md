# 連續性檢查清單

- 一個全新的 Agent 能否在五分鐘內識別近期的工作？
- 目前穩定的啟動路徑是否有記錄？
- 未完成的工作是否已被清楚標示？
- 是否可以在不閱讀舊的聊天記錄的情況下看到下一個最佳任務？
