# 指令檔案反模式

- 將所有 repo 知識放入單一檔案
- 在多個地方重複相同的規則
- 編寫無人審核的過時規則
- 撰寫過於具體而鮮少適用的條件式指令
- 在啟動脈絡中嵌入冗長的工具手冊
