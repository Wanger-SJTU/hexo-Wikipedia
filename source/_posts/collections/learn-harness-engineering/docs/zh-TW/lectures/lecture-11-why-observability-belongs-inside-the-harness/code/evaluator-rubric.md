# 評估評分標準範例

對每個維度使用 1-5 分評分：

- 基礎性：答案是否清楚地與匯入的來源相關聯？
- 引用品質：來源參考是否可見且具體？
- 功能性：使用者能否完成問答流程？
- 產品一致性：工作流程是否感覺整合良好？
