# Sprint 合約範例

Sprint 目標：

- 為基於來源的問答結果新增可見的引用

完成的定義：

- 使用者提出問題
- 應用程式回傳答案
- 顯示至少一個引用
- 點擊引用會在文件檢視中開啟來源位置
