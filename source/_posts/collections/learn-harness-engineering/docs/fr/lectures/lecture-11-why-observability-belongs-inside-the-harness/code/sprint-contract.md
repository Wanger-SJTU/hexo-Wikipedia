# Exemple de Contrat de Sprint

Objectif du sprint :

- Ajouter des citations visibles aux résultats Q&A fondés

"Terminé" signifie :

- L'utilisateur pose une question
- L'application renvoie une réponse
- Au moins une citation est affichée
- Cliquer sur une citation ouvre l'emplacement source dans la vue document
