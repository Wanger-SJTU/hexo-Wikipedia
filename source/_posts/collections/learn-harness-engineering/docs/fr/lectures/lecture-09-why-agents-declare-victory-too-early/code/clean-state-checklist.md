# Liste de Contrôle d'État Propre

- L'application démarre sans réparation manuelle
- La progression actuelle est enregistrée
- Aucune étape d'importation ou d'indexation à moitié terminée ne reste non documentée
- Le prochain agent peut exécuter immédiatement le chemin standard de démarrage et de vérification
