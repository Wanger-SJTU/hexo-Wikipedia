# Index des spécifications produit

Utilisez ce dossier pour les spécifications actuelles du comportement visible par l'utilisateur.

## Spécifications actives

- `new-user-onboarding.md`

## Règles

- Les spécifications doivent décrire le comportement visible par l'utilisateur et les critères d'acceptation.
- Si l'implémentation diverge de la spécification, mettez à jour l'une d'entre elles au cours de la même
  session.
- Maintenez cet index à jour pour qu'un nouvel agent puisse découvrir rapidement le périmètre produit.
