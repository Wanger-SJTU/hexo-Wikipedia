# Plans actifs

Gardez un fichier markdown par plan d'exécution actif dans ce dossier.

Modèle de nommage suggéré :

- `YYYY-MM-DD-short-topic.md`

Chaque plan actif devrait être suffisamment à jour pour qu'une nouvelle session d'agent
puisse reprendre le travail à partir du seul dépôt.
