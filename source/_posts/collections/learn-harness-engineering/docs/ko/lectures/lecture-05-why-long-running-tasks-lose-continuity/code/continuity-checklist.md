# 연속성(continuity) 체크리스트

- 새로운 에이전트가 5분 이내에 최근 작업을 파악할 수 있습니까?
- 현재의 안정적인 시작 경로가 문서화되어 있습니까?
- 미완료 작업이 명확히 식별되어 있습니까?
- 이전 채팅 로그를 읽지 않고도 다음으로 가장 좋은 작업이 보입니까?
