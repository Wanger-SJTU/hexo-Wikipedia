# 명령 파일 안티패턴

- 저장소의 모든 지식을 하나의 파일에 넣기
- 여러 곳에 동일한 규칙을 반복하기
- 아무도 감사하지 않는 오래된 규칙을 유지하기
- 거의 적용되지 않는 지나치게 구체적인 조건부 명령 작성하기
- 긴 도구 설명서를 시작 컨텍스트에 포함하기
