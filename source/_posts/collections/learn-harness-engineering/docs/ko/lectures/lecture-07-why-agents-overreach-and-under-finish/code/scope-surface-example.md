# 범위 표면(Scope Surface) 예제

작업:

- Electron 지식 앱에 인덱싱 기능 추가

나쁜 범위 형태:

- "인덱싱 구현"

더 나은 범위 형태:

- 가져온 문서 파싱
- 문서를 청크(chunk)로 분할
- 청크 메타데이터 영속화
- UI에서 인덱싱 상태 노출
- 재인덱싱 액션 추가
