# 클린 상태 체크리스트(Clean State Checklist)

- 수동 수리 없이 앱이 시작됩니다
- 현재 진행 상황이 기록되어 있습니다
- 문서화되지 않은 반완성 가져오기(import) 또는 인덱싱 단계가 남아 있지 않습니다
- 다음 에이전트(agent)가 표준 시작 및 검증(verification) 경로를 즉시 실행할 수 있습니다
