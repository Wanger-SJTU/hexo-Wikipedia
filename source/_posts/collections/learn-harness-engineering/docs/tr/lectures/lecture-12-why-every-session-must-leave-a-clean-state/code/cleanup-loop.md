# Temizleme döngüsü örneği

Yinelenen temizleme görevleri:

- güncel olmayan belgeleri tara
- yapısal ihlalleri tara
- kalite notlarını güncelle
- hedeflenmiş temizleme PR'ları aç
- temizlemeden sonra sabit bir karşılaştırma dilimini yeniden çalıştır
