# Temiz durum kontrol listesi

- Uygulama, manuel onarım gerekmeden başlıyor
- Mevcut ilerleme kaydedilmiş durumda
- Yarım kalmış bir içe aktarma veya dizinleme adımı belgelenmemiş şekilde kalmamış
- Bir sonraki ajan, standart başlatma ve doğrulama yolunu hemen çalıştırabilir
