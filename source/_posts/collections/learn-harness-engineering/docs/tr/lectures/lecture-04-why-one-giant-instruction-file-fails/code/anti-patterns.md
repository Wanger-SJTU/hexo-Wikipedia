# Talimat dosyası anti-desenleri

- Tüm depo bilgisini tek bir dosyaya koymak
- Aynı kuralı birden çok yerde tekrar etmek
- Kimsenin denetlemediği eski kuralları kodlamak
- Nadiren geçerli olacak kadar spesifik koşullu talimatlar yazmak
- Başlangıç bağlamına uzun araç kılavuzları gömmek
