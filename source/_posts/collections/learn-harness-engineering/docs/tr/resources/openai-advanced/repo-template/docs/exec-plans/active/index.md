# Aktif Planlar

Aktif yürütme planı başına bir markdown dosyasını bu klasörde tutun.

Önerilen dosya adı örüntüsü:

- `YYYY-MM-DD-short-topic.md`

Her aktif plan, yeni bir ajan oturumunun çalışmayı yalnızca depodan devam
ettirebilmesi için yeterince güncel olmalıdır.
