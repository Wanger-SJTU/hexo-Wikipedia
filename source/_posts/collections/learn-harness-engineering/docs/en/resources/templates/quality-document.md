# Quality Document

A quality snapshot for each product domain and architectural layer. Both agents and humans can use this document to quickly understand where the codebase is strong and where it needs work.

<strong>Update cadence:</strong> After each significant session, or before starting a new phase of work.

<strong>Grading scale:</strong>

- <strong>A</strong>: All verification passing, clean architecture, agent-legible, stable tests
- <strong>B</strong>: Verification passing, mostly clean, minor gaps in legibility or test coverage
- <strong>C</strong>: Partially working, known gaps, some code areas hard for agents to understand
- <strong>D</strong>: Not working, or major structural issues
