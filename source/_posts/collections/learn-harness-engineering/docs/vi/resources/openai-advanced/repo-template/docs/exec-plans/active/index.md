# Kế hoạch Active

Giữ một tệp markdown cho mỗi kế hoạch thực thi active trong thư mục này.

Mẫu tên tệp đề xuất:

- `YYYY-MM-DD-chu-de-ngan.md`

Mỗi kế hoạch active nên đủ hiện tại để một phiên agent mới có thể tiếp tục công việc chỉ từ kho lưu trữ.
