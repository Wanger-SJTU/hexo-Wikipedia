# 评估者评分标准示例

对每个维度使用 1-5 评分：

- 基础性：答案是否清晰关联到导入的来源？
- 引用质量：来源引用是否可见且具体？
- 功能性：用户能否完成问答流程？
- 产品一致性：工作流是否感觉一体化？
