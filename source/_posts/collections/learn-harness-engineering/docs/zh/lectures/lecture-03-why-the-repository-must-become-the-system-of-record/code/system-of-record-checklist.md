# 系统记录检查清单

一个全新的 Agent 能否仅从仓库中发现以下信息？

- 正在构建什么产品？
- 应用应该为用户做什么？
- 代码库是如何组织的？
- 应用如何启动？
- 如何检查健康状态？
- 当前正在进行什么工作？
- 哪些质量标准很重要？
