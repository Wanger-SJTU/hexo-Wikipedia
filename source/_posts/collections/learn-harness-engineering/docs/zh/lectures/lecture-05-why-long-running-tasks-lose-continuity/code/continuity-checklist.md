# 连续性检查清单

- 一个全新的 Agent 能否在五分钟内识别最近的工作？
- 当前稳定的启动路径是否有文档记录？
- 未完成的工作是否被清楚标识？
- 下一个最佳任务是否在不阅读旧聊天记录的情况下可见？
