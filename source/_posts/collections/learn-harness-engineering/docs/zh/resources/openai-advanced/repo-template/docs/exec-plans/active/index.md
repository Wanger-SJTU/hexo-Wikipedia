# 当前执行计划

这个文件夹里每一份 markdown 都代表一份当前仍在执行的计划。

建议文件名格式：

- `YYYY-MM-DD-short-topic.md`

每份 active plan 都应该足够新，让一个没有聊天上下文的新 agent 也能只靠仓库继续推进。
