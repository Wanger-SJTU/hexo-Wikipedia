# مثال على حلقة التنظيف

مهام تنظيف متكررة:

- فحص المستندات القديمة
- فحص الانتهاكات الهيكلية
- تحديث درجات الجودة
- فتح طلبات سحب تنظيف مستهدفة
- إعادة تشغيل شريحة معيار ثابتة بعد التنظيف
