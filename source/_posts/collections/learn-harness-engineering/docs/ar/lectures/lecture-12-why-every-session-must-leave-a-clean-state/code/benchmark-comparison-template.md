# قالب مقارنة المعيار

Harness أ:

- معدل الإكمال
- متوسط المحاولات
- الأخطاء المكتشفة قبل المراجعة البشرية

Harness ب:

- معدل الإكمال
- متوسط المحاولات
- الأخطاء المكتشفة قبل المراجعة البشرية

التفسير:

- أي harness غيّر النتيجة؟
- أي harness غيّر تكلفة الحصول على النتيجة؟
