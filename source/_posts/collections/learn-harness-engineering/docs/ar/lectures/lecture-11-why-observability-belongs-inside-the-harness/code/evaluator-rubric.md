# مثال على معيار التقييم

استخدم تقييم 1-5 لكل بُعد:

- التأسيس: هل الإجابات مرتبطة بوضوح بالمصادر المستوردة؟
- جودة الاستشهاد: هل مراجع المصادر مرئية ومحددة؟
- الوظائف: هل يمكن للمستخدم إكمال تدفق السؤال والجواب؟
- تماسك المنتج: هل يبدو سير العمل متكاملاً؟
