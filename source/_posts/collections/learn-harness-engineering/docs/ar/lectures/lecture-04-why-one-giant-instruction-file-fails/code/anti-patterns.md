# أنماط مضادة في ملفات التعليمات

- وضع كل معرفة المستودع في ملف واحد
- تكرار نفس القاعدة في أماكن متعددة
- ترميز قواعد قديمة لا يراجعها أحد
- كتابة تعليمات شرطية محددة جدًا لدرجة نادرًا ما تنطبق
- تضمين أدوات طويلة في سياق التشغيل
