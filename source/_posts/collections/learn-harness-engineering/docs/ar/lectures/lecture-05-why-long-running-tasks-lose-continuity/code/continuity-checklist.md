# قائمة فحص الاستمرارية

- هل يمكن لوكيل جديد تحديد العمل الأخير في أقل من خمس دقائق؟
- هل مسار التشغيل المستقر الحالي موثق؟
- هل العمل غير المنتهي محدد بوضوح؟
- هل المهمة التالية الأفضل مرئية بدون قراءة سجلات الدردشة القديمة؟
